## 1. 核心概念（≤200 字）

> **璇玑，是一台仍在走动的古代星象仪，也是一本会自己书写的《起居注》。**
> 本机每一个正在运行的智能体，都是浑仪上的一颗星。它们所在的项目是天上的「分野」，它们的一举一动被史官落墨成文。这里没有仪表盘，只有一台被点亮的仪器和一部正在写下的编年史。观测者不是在看数据，是在**值守一场星象**。

**一句话 pitch**：*把你的电脑，变成一座正在观测自己的天文台。*

**情绪关键词**：肃穆、温热、克制、可读、有墨香。不是「赛博」，是「铜器与史书」。

## 2. 艺术总监的判断（做什么 / 不做什么）

### 2.1 要做（三个签名，缺一不可）
1. **浑仪（Orrery）**：同心环、星、五行光带、二十八宿刻度——空间性全部交给 Canvas，必须一眼是「仪器」而不是「雷达图」。
2. **《起居注》**：底部实时账本，每一行都是一次真实事件，**落墨显影 + 钤印/朱批**——时间性全部交给 DOM 文本，必须一眼是「史书」而不是「日志窗口」。
3. **授时（开机）**：三行自检 → 钟鸣 → 光圈展开。约 3.2 秒，可跳过；它是这个产品的「开门礼」。

### 2.2 明确不做（反模式清单，实现时逐条对照）
- ❌ 霓虹青紫 synthwave、紫色渐变、纯黑底 + 高饱和光晕（= haloflux 的皮，禁止靠近）
- ❌ 毛玻璃卡片、圆角 16px 容器、投影卡片墙、Dashboard 瓷砖网格
- ❌ 上世纪的「AI 驾驶舱」：六边形蜂窝、HUD 弧线堆砌、无意义装饰刻度
- ❌ 自发光到看不清字：任何文字区域一律先降光再排字
- ❌ 用 `opacity + translateY` 批量做入场（motion-web 明令禁止）
- ❌ 用 `sin(t)` 驱动主要视觉量（节拍必须来自真实事件；见 §7）
- ❌ 编造数据之外的事实（账本只写真实事件；demo 模式必须打「演练」徽标）
- ❌ 把参考游戏的任何具体图形/图标/字体/配色原样搬来（只迁移机制）

### 2.3 参考吸收表（机制 vs 皮）

| 来源 | 只借这个机制 | 绝不搬这个皮 |
|---|---|---|
| **haloflux** | 节拍时钟驱动一切（没有匀速）、显微数据块、自动运镜、参数台、单 Canvas 零依赖 | 霓虹青紫、光场编织核心、旋转面板圆环的圆形小抄本造型 |
| **群星 Stellaris** | 顶栏资源带 + 右侧 outliner + 银河 hyperlane 线 + 全屏星图留白 | 青绿科幻 UI 的配色与切角、科幻字体、图标语言 |
| **赛博朋克 2077** | 黑黄警示带的**警示语法**、扫描/BD 模式的「视界切换」、故障转场只用于告警 | 霓虹粉青、粗野斜切、故障噪点铺满全屏 |

### 3.5 五行（器用光束的五色，唯一允许的高饱和区）
| 类别 | 五行 | token | hex | 说明 |
|---|---|---|---|---|
| 读取 read（read/glob/grep/ls） | 木 | `--cat-read` | `#5e9c7e` | 生发、输入 |
| 书写 write（write/edit/patch） | 火 | `--cat-write` | `#c0532f` | 显形、创造 |
| 执行 exec（bash/pwsh/run） | 土 | `--cat-exec` | `#b98a4e` | 载物、运转 |
| 通问 net（web_search/web_fetch） | 水 | `--cat-net` | `#4e6e8e` | 流通、外求 |
| 遣使 agent（subagent/team_*/send） | 金 | `--cat-agent` | `#c9bfa6` | 锐利、分派 |

> 使用纪律：五行色**只用于「动作」**（光束、器用计数、账本动作字），绝不用于大面积背景或静态装饰。任何时刻画面上五行色的面积占比应 < 8%。

### 3.6 光
- **唯一主光源**：画面中心偏上的暖光（油灯/烛火），`radial-gradient(circle at 50% 46%, rgba(232,200,120,0.10), transparent 58%)`——仪器被灯照着，而不是仪器自己在发光。
- 星光允许辉光，但辉光必须「低饱和、小半径、只在星核附近」；全屏 bloom ≥ 24px 半径禁止。
- 冷色只出现在两处：①边缘远景星野（极淡的 `#8fa0b8`）；②「失联」状态（`#6c7fa0` 灰靛）。
- 暗角（vignette）常开，中心保留亮度，四角压到 0.55 亮度以下，制造 Museum 灯光感。

## 4. 字体系统

| 角色 | 字体 | 用法 | 字重/字号/字距 |
|---|---|---|---|
| 显示标题 | Xuanji Display（霞鹜文楷 500，本地打包） | 开机标题、「起居注」「星牒」「授时」等题头、账本章节名、大号汉字 | 28–44px / 0.06em / 500 |
| 正文（中文） | Noto Serif SC（思源宋体，unicode-range 分片懒加载） | 账本条目、面板正文、提示语 | 13/14px / 0.02em / 400；强调 600 |
| 数字与拉丁 | JetBrains Mono | 所有指标数字、时间码、token 计数、路径、快捷键、ID | 11–13px / 0.04em / 400–500，`font-variant-numeric: tabular-nums` |
| 微型标签（拉丁） | JetBrains Mono 400 | 刻度标签、英文副题、单位 | 9–10px / 0.18em / uppercase |

**排版纪律**
- 中文正文行高 1.75；账本行高 1.6；数字行高 1.2。
- 汉字与数字混排时，数字前后各留 0.15em 空隙（`padding-inline: .15em`）。
- 允许**竖排**，仅限一处：右侧「分野」标签沿环竖排（`writing-mode: vertical-rl`），其余一律横排。
- 禁止：全大写中文、斜体中文、字重 700 以上的中文大标题、任何描边字。
- 数字一律等宽（tabular），保证账本与指标列对齐。

```
├──────────────────────────────────────────────────────────────────────────────┤
│                                                                              │
│      （Canvas 星空 + 浑仪，全屏铺满，顶栏与面板浮于其上、透明背景）              │
│                                                                              │
│                                        ┌───────────────────────────────┐     │
│                                        │ 星牒（选中 agent 详情）        │     │
│                                        │ 或：警情 / 总览（未选中时）     │     │
│                                        └───────────────────────────────┘     │
│                                                                              │
│  ┌──────────────────────────────────────┐                                    │
│  │ 《起居注》                           │        （中央底部：模式序号 + 提示） │
│  │ 落墨条目 × ≤120                      │                                    │
│  └──────────────────────────────────────┘                                    │
└──────────────────────────────────────────────────────────────────────────────┘
```

- **顶栏**：高 56px，底色透明 + 底部 1px 金线；左：产品名（显示体 20px）+「授时」小印；中：时辰（汉字）+ 日期 + 等宽时间码；右：指标组（每条：微型大写中文标签 + 等宽数字），末尾状态徽标与模式序号。**全程无卡片、无圆角、无背景块**。
- **《起居注》**：左下沉底面板，宽 `clamp(340px, 36vw, 560px)`，高 `min(34vh, 360px)`；无外框，仅顶部 1px 线 + 渐隐遮罩；标题为竖排小章 + 横排「起居注 · 卷〇〇」。
- **星牒**：右侧面板，宽 320px，垂直居中偏上；未选中时显示「警情/总览」，选中时化入 agent 详情。出现/消失用「卷轴展开」：宽度 0→320px + 内容落墨，而非淡入淡出。
- **中央底部**：模式序号（如「贰 · 逐星」）+ 一行提示（`↑↓ 择星  Enter 勘验  L 起居注  / 调参  ? 快捷键`）；透明度 0.55，任何面板展开时可让位隐藏。
- **安全区**：面板与顶栏之外，画面中心 60% 区域永远留给浑仪，不允许压任何文字。

## 6. 签名装置一：浑仪（Canvas）

### 6.1 几何（以短边半径为 R，`R = min(vw, vh) * 0.46`）
| 元素 | 半径 | 说明 |
|---|---|---|
| 中枢·紫宫 | 0 – 0.10R | 水漏钟摆 + 三嵌套转环 + 圭表（gnomon）；中心一颗暗金色「枢星」 |
| 五行光带 | 0.16R – 0.30R | 五条极细同心环带，见 §6.4 |
| 星轨（depth 层） | 0.34R / 0.46R / 0.58R | depth 0 = 主 agent；depth 1 = 子 agent；depth 2+ = 更深后代 |
| 分野弧带 | 0.66R – 0.74R | 每 workspace 一段圆弧，含竖排分野名 + 该域星数 |
| 授时刻度环 | 0.78R – 0.86R | 二十八宿刻度、12 时辰、活动指示；静态图层，离屏缓存 |
| 星野 | > 0.88R + 全画面 | 远景星点（视差分层）、尘埃、极淡云气 |

### 6.2 星（= agent）
- **位置**：极坐标。角度 = 所属分野弧的角度区间内 + 会话哈希偏移；半径 = 0.34R / 0.46R / 0.58R 按 depth。星的角度缓慢漂移：`angle += activity * 0.02 rad/s`，活动越高越「绕行」；idle 星几乎静止。这一切由节拍时钟的 `energy` 调制，不匀速。
- **半径**：`starR = clamp(2.2 + log10(outputTokens + 1) * 1.05, 2.2, 9) * (1 + beatPulse*0.25)`；选中放大 1.35×。
- **呼吸**：live 星亮度按 `pulse` 起伏（每次事件推高、按 `pulseDecay` 衰减），idle 星无呼吸，ended 星无光。
- **形状双编码**：live 实心 + 外环；idle 实心无环；ended 空心环；error 三角缺口；approval 双环 + 玉色。**必须做到色盲可辨**。
- **星过留痕**：每次 `step/end` 或 `turn/end`，在该星所在轨道环上留下一段 0.6°–1.6° 的墨痕弧，亮度随 20s 衰减；轨道环因此逐日「被写满」。这是产品的时间感。
- **卫星**：子 agent 以 0.34R 外的卫星点存在，与父星之间有一根极淡金色虚线（派生弧）；遣使类工具生效时虚线亮 400ms。

### 6.3 分野（workspace = 星次）
- 每个 workspace 占一段圆弧（按 live 数 + 会话数加权分配角度，最小 18°），弧带上有分野名（竖排，显示体 12px）与该域星数（mono）。
- **分工例外（2026-10 修订）**：与几何强绑定、必须逐帧跟随空间的世界内标注（分野名、授时刻度、星名 hover 标签、器用类别小字）允许由 Scene 用 Canvas 绘制；**所有界面文字、账本、面板、按钮、数字指标仍全部 DOM**。这样避免 scene↔hud 每帧传递坐标的耦合。
- 全局只有一个「分野」层，不分主次；未归属 workspace 的会话归入「野 · 未隶」段。
- 分野弧带随环整体缓慢转动（`ringSpeed`），但**每 7±3 拍停顿急停一次**（擒纵机构），停顿 180–420ms，重启时带 8% 过冲回弹。

### 6.4 五行光带（器用）
- 五条同心环带，由内到外：木（读取）→ 火（书写）→ 土（执行）→ 水（通问）→ 金（遣使）。
- **基础亮度 = 该类工具近 60s 速率**（平滑），静止时只有 8%–12% 的暗刻线。
- **一次工具调用 = 一道「笔触」**：从该星朝内射向中枢，穿过对应五行带时留下 120–260ms 的亮痕（长度随工具名长度 40–90px），沿线有 2–4 个微小墨点。错误工具：笔触在带外侧 30% 处**断墨**，并在断点留 1 颗朱砂点，300ms 后坠落消失。
- 五带在节拍的强拍上同时轻颤一次（位移 ≤ 0.6px），弱拍只颤「最近有动作」的那一条。
- 遣使（agent）不画入内笔触，而是画**两颗星之间的连线**（父→子/team 协作），线为实金细线 + 端点小环，持续 600ms。

### 6.5 刻度环（授时）
- 最外一圈静态「錾刻」图层（离屏 canvas，DPR 缓存）：28 宿名刻度 + 12 时辰 + 60 小刻；线宽 1px，颜色 `--gold-500` 到 `--gold-400` 渐变，随活动有 0.2% 的微光。
- 当前时辰的刻度有一小段 `--gold-200` 亮起，并随真实时钟走（不是动画假走）。
- 环上刻点：live 会话 -> 每隔一段有一颗亮点，靠近所属分野弧。

### 6.6 相机与运镜（7 式）
| 模式 | 键 | 取景 | 备注 |
|---|---|---|---|
| 云图 survey | 1 | 全局，轻微俯瞰、R 的 1.0 倍 | 默认；含最完整星野 |
| 逐星 track | 2 | 跟随选中星，推近到 1.9–2.6×，被跟随星固定在画面黄金分割点 | 选中星不漂出画面 |
| 勘验 dossier | 3 | 推近至 3.2×，星单独isolated，其余降亮 40%，星牒展开 | 与 DOM 面板联动 |
| 起居注 ledger | 4 | 拉远至 0.82× 并上移，让出底部账本空间；场景降亮 25% | |
| 浑仪 orrery | 5 | 正对仪器，1.25×，强刻度、弱星野 | 「仪器模式」 |
| 拂扫 scan | 6 | 全局 + 扫描光带 3.6s 扫一圈，异常星被高亮方框锁定 | 只扫异常/高压力 |
| 守夜 vigil | 7 | 极慢推近，1.1×，只亮 live 星，其余近乎沉入暗处 | 专注模式 |

- 转场「推近后定住」：900–1400ms，`ease-in-out` 前 60% 完成 80% 位移，最后 40% 只做 2–4px 的「定住」微调；禁止匀速平移。
- **自动运镜（auto-director）**：停留 9–18s（`dwell` 参数），按事件抢占：`error/approval > turn/start > tool/call 密集 > 轮转`；无人值守时 30s 一次「全景呼吸」。
- 手动操作后 60s 内不自动抢镜（`manualReturn` 参数 3–20s 可调）。
- 鼠标拖拽 = 环面视差（最大 ±0.6R 的极轻微位移），滚轮 = 0.8×–1.6× 缩放；`prefers-reduced-motion` 时运镜只做 200ms 淡切。

## 7. 节拍时钟（Beat Clock，一切非匀速的来源）

**原则：节拍必须由真实事件能量驱动，禁止 `sin(t)` 直接驱动主要视觉量。**

```
eventBurst  = 近 1.5s 事件数 / 12（clamp 0..1.5）
tokenRate   = aggregates.tokenRate（tokens/s，平滑）
liveCount   = aggregates.liveCount
focusEnergy = 选中星近 10s 事件数 / 6
energy      = smooth(0.35*eventBurst + 0.02*tokenRate + 0.08*liveCount + 0.2*focusEnergy)   // 0..~1.6
tempo       = 0.28 + 0.95 * energy * tempoGain          // Hz，0.28–1.9
```
- 每拍间隔加 ±12% 抖动；每 7±3 拍出现一次「弱拍」（间隔 ×1.55）；强拍每 8 拍一次（间隔 ×0.72）。
- 拍点用途：中枢水滴涟漪、五行带轻颤、刻度环微亮、星呼吸相位重置。**所有周期量都从拍点派生**（用 `beatPhase` 与 `sinceBeat`），不要各自写 `sin`。
- 擒纵（环转动）：`ringVel → 加速 160ms → 匀速 → 急停（180–420ms，位置保持）→ 8% 过冲回弹 → 重启`；停顿时长与 eventBurst 正相关。
- 空闲（无事件 > 6s）：tempo 降到 0.3Hz，画面进入「守夜呼吸」——每 3 拍一次极轻的全局亮度起伏（幅度 3%）。

字段规则：
- 时间：汉字时辰 + 刻，附 `HH:MM:SS` 的 mono 小字（hover 才显；默认只显示时辰）。
- 星名：会话标题（截 24 字，超出省略号）；分野名次级小字。

- 上限 120 条 DOM，超出移除最旧；新条目进入时若用户正在向上滚动阅读，**不自动滚动**，改在底部显示「新墨 ↓」浮标。

- 失联态：账本顶部一条 `墨尽 · 与采集器失联，正在重连……`（朱批色描边），恢复后补写「续」。

## 11. 动效系统

### 11.1 tokens
| token | 值 | 用途 |
|---|---|---|
| `--dur-instant` | 90ms | 按钮反馈、刻点闪 |
| `--dur-fast` | 180ms | 钤印落下、hover |
| `--dur-mid` | 320ms | 面板展开、落墨 |
| `--dur-slow` | 620ms | 星牒卷轴、模式切换（部分） |
| `--dur-cinematic` | 1100ms | 运镜转场（上限 1400） |
| `--ease-out` | `cubic-bezier(.16,1,.3,1)` | 入场 |
| `--ease-engrave` | `cubic-bezier(.22,.9,.24,1)` | 落墨/錾刻 |
| `--ease-in-out` | `cubic-bezier(.65,0,.35,1)` | 运镜 |

### 11.2 禁止的动效
- 卡片整体 `opacity+translateY` 入场（motion-web 反模式）
- 无限循环的装饰性旋转/呼吸（除了仪器自身的、由节拍驱动的转动）
- 弹簧物理用于数据展示（数据必须「重、稳、有惯性但不撒欢」）
- 鼠标跟随的 spotlight/光斑
- 数字滚动动画超过 600ms（数字要快速准确；用 mono 等宽 + 0.3s 数值过渡）

## 17. v1.1 研究校准（2026-10-27，五参考系报告全部到手后）

### 17.1 三段材质（冷 / 温 / 纸）
- **远**（星野 >0.88R、远景尘、星轨暗部）：冷月蓝 —— `--cold-300 #8fa0b8`、`--indigo-400 #6c7fa0`，alpha 4–16%，面积可大；远景物平均饱和度 ≤18%。
- **中**（浑仪本体、刻度、星、分野弧）：暖金/铜 —— gold 100–500，线宽 1px；浑仪是画面里唯一「亮而有实体」的东西。
- **近**（《起居注》、星牒、帮助、调参台）：骨白纸 —— bone 100/200 文字 + ink-deep 底，像档案页，不是玻璃卡片。
- 抗漂移判据：同一小部件里不同时出现「金线」与「纸面」两种材质；冷暖面积不得 1:1（冷=远可大但弱，暖=近小但强）。

### 17.2 分层轮盘（取「环宽即层级」，不取其图形）
- 分野弧带由 12 个 30° 主分割线界定（1px，alpha 0.18–0.22），其间再细分小刻；每个 workspace 占一个或多个扇区，扇区内按 agent 哈希角度分布。

- 授时环刻度三档：每 30° 主刻（1px × 6px）、每 1° 次刻（0.75px × 3px）、每 0.25° 微刻（0.5px × 1.5px）；二十八宿/十二时辰标签只在 ≥1440px 宽时显示。

### 17.3 档案行（《起居注》与星牒表格）
- 行高：桌面 28px（密）/ 宽屏 32px；**无竖线、无斑马纹、每行不卡片化**。

- 时间/数字列右对齐、JetBrains Mono tabular-nums；文本列左对齐。
- 分组用**一条** 1px 金线（`--ink-line-strong`）通栏，上下各 12px；组内不再重复线。

- 全局语义色只 5 个：live 金 / idle 骨白 / ended 灰 / error 朱 / approval 玉；「金」不再用于强调按钮（避免与 live 冲突）。强调靠字重、字距、1px 线，不靠颜色。

### 18.2 藏星法则（本机所有 agent 一律可见）
- 本机 125 个会话里通常只有 1–4 个 live，其余全部 ended。**ended 不许隐形**：实心淡骨白（alpha ≈0.42）+ 1px 外环（alpha ≈0.5），最低绘制半径 1.6px；idle alpha ≈0.72 带微呼吸；live 保持金实心 + 外环。选中/悬停再提亮，不做全局提亮。

## 20. v2.1 视野主权与深看（2026-10-28，用户 m01655 后新增）

> 用户原话（m01655）：「让它不要自动移动视野到中心，现在这样自动回复无法看清细节以及自定义」。
> 结论：把取景的**所有权**从「自动导演」交还给人——默认不动，人一动就锁，锁到人主动放开。

### 20.1 视野主权三定律

1. **默认不动**：`autoDirector` 默认 0。首屏、刷新、切预设后，镜头都不自行转场；只有用户按 `Space`（或调参台把「自动运镜」打开）才启动自动导演。
2. **人一动就锁**：任何手动操作——滚轮缩放、拖拽、双击复位、点分野行聚焦、按 `1`–`7` 切机位、点星/Enter 勘验——立即**取消正在进行的转场**并把自动导演锁死（而非「冷却 N 秒后回来」）。锁定期间任何事件（错误、审批、新轮次）都**不得抢镜**。
3. **人主动放开**：`Space` 是唯一的解锁/上锁开关。开锁时 HUD 播报「自动运镜 · 开」，并给 3s 宽限（从当前视野开始，不瞬间跳中心）；关锁时播报「视野已锁定 · Space 恢复自动运镜」，只在当次提示一次。

### 20.2 深看（看清细节）

- 滚轮缩放范围扩大到 **0.75–6.0×**（原 2.4×），总缩放钳制 0.5–8.0；缩放到 1.2× 以上时，世界内文字（分野双行标注/宿名/五行小字）按 `screenGrow/zoom` 反缩放，**屏幕字号随缩放明显增大**：`screenGrow = clamp(1.08·√zoom·layout·boost, 1, 5)`（首屏 1.12×→约 1.60×、2.4×→约 2.35×、6.7×→约 3.92×），其中 `layout = clamp(√(R/450),1,1.6)` 让大窗口/全屏时字也变大，`boost` = 调参台「质感 → 字号」`textBoost`（0.8–2.4，**默认 1.4**，URL `?p=textBoost:1.8`）；屏幕坐标系的标签（星名/进程名）直接用 `screenGrow` 作字号倍数。**放大时字只会变大，绝不缩小**（v2.4.1 修订：此前屏幕坐标标签误乘了 ≤1 的反向系数，放大反而变小；v2.4.2 修订：提高幅度并加窗口尺寸项与可调 boost；v2.4.3 修订：默认 boost 1→1.4、上限 1.6×→约 3.9×，因用户反馈「还是小」）。
- **缩放锚点 = 鼠标光标**：滚轮时保持光标下的世界点不动（不再总是把视野拉回中心），这样可以对准任何一颗星或任一处分野细节放大。

### 20.3 视野记忆（自定义）

### 20.4 提示文案

- 底部提示从「Space 暂停自动运镜」改为「`Space` 自动运镜（关）／（开）」，状态实时反映；帮助面板加一行「视野会记住：滚轮对准细节放大 · 双击复位 · 刷新不丢」。

## 21. v2.2 丝滑缩放与轨道混沌（2026-10-28，用户 m01918 后新增）

> 反馈原文：「缩放的时候不够丝滑，画面在跳动；以及圈中的小球排列和旋转可以稍微混乱一点，不要重合，每个轨道的速度不要一致。」

### 21.1 丝滑缩放（消除跳动）

- 滚轮只改「目标缩放」`zoomGoal`（乘性累加、clamp 0.75–6.0）；**不再**在事件里直接设 `zoomUser`，**不再**用单次事件补偿 drag。
- 每帧：`zoomUser = damp(zoomUser, zoomGoal, 16, dt)`；`cam.zoom = damp(cam.zoom, targetZoom, 26, dt)`（单级快跟随，避免 v2.1 的两级滞后）。
- 每帧一次性消费累计滚轮 delta（`pendingWheel`），禁止一帧多跳；手势期间（`now - lastWheelAt < 260ms`）`zoomGoal` 平滑累积。
- **锚点每帧求解**：手势起点记录 `{sx, sy, worldX, worldY}`（首个滚轮事件用 `screenToWorld` 求 world），之后每帧在 cam 更新后反解 `drag`，使该世界点始终停在光标下；偏差 >0.5px 才修正，避免抖动。
- **静态离屏层不在跨档瞬间重绘**：跨档只记 `pendingTier`；当「缩放速度连续 140ms < 0.002/帧」或手势结束 240ms 后才重烘；重烘进分帧队列（每帧最多 1 个子系统：instrument → micro → air → sky），手势中禁止重烘。
- 跨档过渡用 **180ms 交叉淡入**（旧静态层 canvas 与新层按 alpha 混合），禁止硬切。
- 双击复位也走 `zoomGoal = 1` + 平滑归零（禁止瞬跳）。
- 验收（qa-v22 `smooth.*`）：滚轮连打 8 次（累计 -1400）时每帧 zoom 比值 ≤1.10、回落比 ≥0.9、≤1.2s 收敛；平均帧 ≤22ms；锚点漂移 ≤40px。

### 21.2 轨道混沌（不重合、不同速）

- **每个轨道层独立角速度**：`zoneRot[z] += zoneSpeed[z] * dt * (0.55 + 0.45*energy)`；`zoneSpeed[z] = 0.048 * [1.00, 0.63, 0.41, 0.78, 0.52, 0.33][z] * hashJitter(0.85–1.15)`；约 30% 层反向（hash 决定）。禁止所有层同速同向。
- **每颗星自身还有游速**：`speedK = 0.55 + hash01(id)*1.05`（0.55–1.60）；drift 速度 = `0.022 * (0.12 + 0.88*activity) * speedK`。ended 星保留 0.12 底速缓慢游走（比 live 慢一个量级）。
- **半径分层**：`radius = R*(orbitIn + (orbitOut-orbitIn)*((z + (hash01(id)-0.5)*0.42)/ringCount))`，再加 ±2.5% 极缓慢呼吸（周期 40–120s，只作二次动效，不得用 sin(t) 驱动主视觉）。
- **角度不规则**：分野弧内 `frac = clamp((i + 0.06 + 0.88*hash)/n)` + ±0.35 个相邻间距的抖动；布局后跑一次**反重合松弛**（按 12px 半径带分组、按角度排序，最小屏距 ≥ max(6px, 两星半径和+3px)，沿环推开，最多 6 轮）。
- **卫星**：每颗卫星独立角速度 `0.18 + hash*0.5` rad/s + 独立方向，禁止同速。
- 静观/守夜预设混沌幅度 ×0.55；reduced-motion ×0.3（仍保持速度不同，只是更慢）。
- 验收（qa-v22 `orbit.*`）：`debugOrbits()` 提供 `{ zones: [{index, speed}], stars, minPairDist, speedSpread }`；轨道层速度两两差 ≥2%；speedSpread ≥1.4；同屏 minPairDist ≥5px；间隔 3s 两次采样 minPairDist 退化 ≤20%。

## 22. v2.3 稳定 · 层级 · 机器运转 · 复合核心 · 双主题（2026-10-28，用户 m02094 后新增）

> 用户原话要点：「小球在运动时会不断闪烁，错位；缩放时画面亮度闪烁；让越庞大且越活跃的小球靠近中心；动效太简陋，没有参考项目那种机器运作大量数据交互传递的感觉；agent 工作时对应外环板块要有效果反馈；agent/会话/工作区之间的协作与通讯要有动效；新增小球/会话/agent/工作区要有实时动画；中间核心不够复杂；再做可切换科幻主题」。

本版所有新动效**必须由真实数据驱动**（事件、tokens、toolRate、source 状态）；无真实数据可用的地方用固定拍点/哈希，不编造事实。

### 22.1 运动稳定性（治「闪烁 / 错位」）

禁则（违反任何一条即验收不过）：

1. **绝对禁止任何位置瞬移**。删除 `stars.ts` 里 `if (Math.abs(delta) > 0.06) star.angle = target` 这类 snap；改为「**轨道过渡态**」：目标角差 >0.06 rad 时按**最大角速度 1.6 rad/s** 追赶（约 26°/s），过渡期沿当前半径的弧线插值，不得穿越另一个分野弧段。
2. **速率上限**（每帧 @60fps）：角度修正 ≤0.004 rad、径向位移 ≤1.2px、alpha ≤0.06、半径 ≤0.12px。`resolveSeparation()` / `enforceFloor()` 不再直接改写位置，而是算出「期望位移」再按速率上限积分；ended 星让位优先，live/idle 星不动。
3. **闪烁根因禁止**：`twinkle` 不用「每 640ms 随机跳变」，改为**多倍频正弦**叠加（三频互不整除：0.31 / 0.53 / 0.87 Hz + 星 id 相位），幅度 ≤8%，乘在 alpha 上；其余随机闪烁一律 damp。
4. **数据驱动的视觉量只改目标值**：星半径、亮度、环宽、角度都要经过 `damp(λ 6–10)`，不得因 `tokens`/`state` 变化单帧跳变。
5. scene 暴露 `debugMotion(): { teleports, maxAlphaStep, frames, brightness }`——位置单帧角位移 >0.02rad 或径向 >3px 记一次 teleport；alpha 单帧跳变取最大。窗口取最近 200 帧。

### 22.2 缩放亮度稳定（治「缩放时画面亮度闪烁」）

1. 手势期禁止后期效果**硬开关**：景深 blur / 辉光 / 色散 / 颗粒 / 星野 / 尾迹统一改用一个 `fxWeight`（1 → 0.55，240ms ease-in-out），跨档交叉淡入时两版同屏总 alpha ≤1.05。
2. 手势中禁止切换 `shadowBlur` / `globalCompositeOperation` 模式（会突变）。
3. 验收（qa-v23 `brightness`）：
   - **闪烁**用「相邻采样帧亮度跳变」判定：滚轮连打期间每 ~90ms 采样一次 64×36 降采样均亮度，相邻帧相对跳变 ≤8%；
   - **允许**由构图变化造成的缓变（例如放大到更亮的核心区，整体亮度可以缓慢上升）——只禁止高频闪烁与硬跳。因此不以「相对起始帧偏差」为判据。

### 22.3 径向层级：越庞大、越活跃 → 越靠内

- `weight = 0.55*normLog10(outputTokens+1) + 0.35*activityNorm + 0.10*liveBonus`（activity = 近 60s token/tool 速率归一；liveBonus = live ? 1 : 0）。

- 视觉预期：内圈形成「高亮密集带」，外圈是沉寂/轻量星。
- 验收（qa-v23 `hierarchy`）：`debugHierarchy()` 的 `spearman` ≤ -0.5；`innerAvgWeight - outerAvgWeight ≥ 0.15`；live 星平均半径比 ended 小 ≥0.05R。

## 24. v2.5 第三视图「百工 · 器群」（2026-10-28，用户 m03711 后新增）

> 用户原话要点：「在智能体/主机这两个模式外加入第三个模式，这个模式将会把本地所有进程都可视化展示，整体风格类似于『智能体』模块，但是要有明显区分，风格设计的核心主旨是体现庞大的数据流和无感情波动极致理性的机械运作，要与『智能体』模块那种伴随数据流动而思考的生动相区分开来。」
> **一句话**：同一台仪器换第三组盘面——观星是「活的」星与分野；观机是「一整台」机器的仪表；**百工是「拆开机器看每一个零件在怎么转」**：无呼吸、无留痕、无随机、无缓动，只有等速的直线、等距的刻度、严格 1 Hz 的机械步进。

### 24.1 与「智能体」视图的对立（设计总纲）

| 维度 | 智能体（观星） | 百工（器群） |
|---|---|---|
| 形体 | 圆星、柔光、曲线弧 | **矩形芯片、1px 硬边、直线** |
| 运动 | 不均匀节拍、阻尼缓动、呼吸 | **严格 1 Hz 步进、恒定速度、无缓动** |
| 颜色 | 暖金 + 骨白（铜器与史书） | **钢灰 + 冷白（去温度）**；暖金禁用 |
| 数据表达 | 光流、光包、笔触、涟漪 | **等速行进虚线（marching）、满格填充、计数** |
| 痕迹 | 星过留痕、涟漪残留 | **无痕迹**：过去了就是过去了，不留影 |
| 情绪 | 有生命、在思考 | **无情、精确、庞大** |

反模式：不得在百工复用星形/分野弧/星过留痕/呼吸/随机抖动/暖金主色/辉光核心；不得用「数据雨」制造廉价密度。

### 24.2 几何（`R` 与观星一致）

- 中心 **机轴**：0.10R 八边形轮毂（1px 描边 + 8 根辐条），每 tick 步进 6°（见 24.4）。
- 三档轨道 **rail**：CPU 轨 0.26R、内存轨 0.42R、沉积轨 0.58R；轨线 1px，alpha 0.16，每 15° 一道 3px 刻段。
- **数据总线环**：0.66–0.78R 双层（内 0.66 / 外 0.78），恒定 0.05 rad/s 连续旋转；环上 72 个孔位（5° 间隔），每 tick 依次点亮 1 个（60ms 亮起、400ms 淡出）；环外缘 0.78R 一圈等距 1px 刻度。
- **工程网格星野**：0.80–0.96R，8° 径向线 + 8 等距环线，alpha 0.05；最外 0.96R 四角定位十字。无星点、无 bokeh、无流星。
- 移动端 R 用 `min(vw, vh*0.92)*0.46`；rails 与总线环等比缩，芯片高 +2px 保证可点。

### 24.3 进程芯片（每进程一枚）

- 形状：**矩形，无圆角**；高 5px（移动端 7px）；宽 `clamp(7 + log2(cpuPct+1)*3, 7, 26)` px；1px 描边。
- 分轨（确定性）：`cpuPct ≥ 1` → CPU 轨；否则 `memBytes > 500MB` → 内存轨；否则沉积轨。轨道内按 CPU 降序顺时针排列（重排只发生在集合变化时，角度用 `hash(pid)` 稳定落位，不做每帧漂移）。
- 填充 = CPU 占比（从左往右实心填充，**不是透明度**）：钢灰底 `#8b8c8f`（alpha .55），填充冷白 `#e7eef2`；`cpuPct ≥ 25` 描边冷白；`memBytes > 1GB` 加 1px 内衬线；沉积轨 alpha .5。
- 颜色双主题：璇玑 = 钢灰 `#8b8c8f` + 冷白 `#e7eef2` + 骨白 `#d3cbb6`；深空 = 青蓝 `#5fd0ea` + 荧光青绿 `#7df0c4` + 冷白 `#f2f9ff`。**禁止 shadowBlur**（只允许 1px 描边）。
- 数量上限 220（= 后端 `PROCS_TOP`）；超出不画，不造假。进程进出：进入 240ms 从总线环外「压入」轨位（线性），退出 240ms 线性淡出；不弹跳、不缓动。

### 24.4 机械节拍（严格、恒定）

- 节拍 = `tickPhase = (now % 1000) / 1000`，**无抖动、无随机、无缓动**。这与观星的「不均匀节拍」是刻意对立。
- 机轴：每 tick 瞬转 6°（步进，不是连续旋转），中间保持不动。
- 总线环：连续恒定 0.05 rad/s；孔位每 tick 亮一个。
- 扫描线：每 4s 一条 1px 水平线自上而下**匀速**扫过（linear，alpha 0.05，只一条）。
- 数值变化：process 数据 2s 一帧，视觉量用**线性插值**（`+ (target-current)*min(1, dt/0.2)`），禁止回弹/过冲；这就是「无感情波动」。
- reduced-motion：取消扫描线与孔位亮灭，保留静态刻度与芯片填充。

### 24.5 数据总线（「庞大的数据流」）

- 每枚芯片一条**径向直线**连到机轴外缘（0.14R），长度 = 芯片所处轨位半径 − 0.14R；**直线，不是曲线/弧**。
- 线型：1px 虚线，dash 2 / gap 3；`lineDashOffset` 以恒定 40px/s 向心行进（marching），alpha 0.18；`cpuPct ≥ 1` 时线宽 `0.6 + cpuPct/25*1.8`（clamp ≤2.4）、alpha 0.18+0.5*cpuPct/40；沉积轨不 marching（静止虚线，alpha 0.07）——「停机」的视觉语义。

## 25. v2.6 百工重做：瀑布 · 径向层级 · 连续轨迹（2026-10-28，用户 m04287 后新增）

### 25.1 气质重置（v2.6，替换 §24 的运动与层级）

v2.5 的百工读起来像「靶盘 + 死水」：三档固定半径、芯片只是极慢漂移、沉积轨几乎不动 → 用户判定「过于简陋，应当像一条凶猛的瀑布，而非一滩死水」。

v2.6 的图景是**落差**：外缘是进水口（雨幕），径向是水道，核心是泄水口 / 涡轮。所有东西朝内、同向、匀速；数据量体现为流宽与粒子密度；没有随机、没有回弹、没有缓动曲线。机械身份（直线、恒速、1Hz 节拍、钢灰冷白）保持不变，与观星视图（曲线、呼吸、暖金）依旧对立。

### 25.2 径向层级：占用越大、启动越新，越靠核心

每枚进程芯片的权重：

```
cpuN   = clamp01(log10(cpuPct + 0.5) / log10(100.5))
memN   = clamp01(log10(memMB + 1) / log10(9000))
recN   = clamp01(1 - ageSec / 604800)        // 7 天线性；age = now - startedAt
weight = clamp01(0.42*cpuN + 0.30*memN + 0.28*recN)
r      = R * (0.30 + (1 - weight) * 0.62)      // 0.30R（最重/最新）～0.92R（最轻/最旧）
```

- 缺少 `startedAt` 的进程取 `recN = 0.35`（中性，不奖励也不惩罚）。
- 角位置 `phi0 = hash(pid) * TAU`；角速度 `omega = 0.004 + 0.016*(1-weight)` rad/s，**全部同向**（外圈略快、内圈略慢，形成缓慢涡旋）；无抖动、无反向、无随机换道。
- 三轨不再是固定半径：只保留 `0.30R / 0.52R / 0.72R` 三条 **参考刻环**（alpha 0.05）与着色分类（主导因子：CPU 冷白 / 内存钢青 / 沉积灰）。分类只决定颜色，不决定半径。

### 25.3 瀑布（v2.6 的核心新装置）

1. **内向数据包（主体）**：每枚芯片持续向核心发射短划数据包，`rate = 2 + 14 * cpuN^0.6` 个/秒（全盘 ≤ 1400 个在途，对象池复用）。包长 2–5px、宽 1–2px，沿芯片当前径向（角度随芯片角速度微动 ≤0.5°/s）以 `speed = 0.55 * env.R` px/s **恒速**向内；`r < 0.14R` 时被核心泄水口吞没（intake 环一次 60ms 闪光）；alpha 由源 0.55 线性衰减到 0.18；颜色 = 芯片色。
2. **入口雨幕（落差顶端）**：外缘 `1.02R–1.10R` 之间，`entryFlow = clamp(round(totalThreads / 3), 8, 220)` 条短划（长 6–14px）自 1.10R 向 1.00R 恒速下落（0.22R/s）；每条相位由 index hash 决定、`(now*speed + hash) mod 长度` 循环，无缝无跳变；密度 ∝ 线程总数。
3. **主排水渠**：沿 24 条径向水道刻槽（alpha 0.04，由外到内贯穿三环）；槽内 6–10 枚「大水滴」（长 8–18px）以 0.4R/s 内向流动。
4. **芯片尾迹**：芯片沿角向运动，身后拖 6° 渐隐弧（alpha 0.10 → 0），保证「有轨迹」而不闪烁。

### 25.4 机械核心（泄水口 / 涡轮）

- 三层：intake 环 `r = 0.14R`（24 齿，每 tick 转 3°）、rotor 八边形 `r = 0.10R`（每 tick 6°）、aperture 暗环 `r ≈ 0.045R` 外缘 1px 冷白。
- 吞吐指示：每 tick 把「上一秒吞入的包数」映射为 intake 环亮度脉动一次（40ms 线性上升 / 160ms 线性下降）；CPU 总量映射 aperture 半径 `0.040R–0.052R`。
- 无自动运镜、无节拍呼吸；只有机械 tick 与 intake 脉动。

### 25.5 轨迹与稳定性（治「随意闪烁」）

- 位置积分：`phi += omega*dt`；`r = damp(r, targetR, λ2, dt)`（仅在数据变化时收敛，绝不瞬移）。
- 禁止任何逐帧随机 alpha / 位置；所有 alpha 单帧变化 ≤0.03；进出场 240ms 线性淡入淡出，不得突然出现或消失。
- 雨幕 / 数据包 / 大水滴的相位全部由「时间 × 速度 + hash」解析计算，循环无缝。
- QA 断言（`debugProcesses()` 暴露）：`chipAngularSpeed` 两次采样同值；`packetSpeedVar ≤ 0.05`；`maxAlphaStep ≤ 0.04`；`hierarchySpearman ≤ -0.5`；`packets ≥ 300`；`entryFlow > 0`；`sceneMs ≤ 8`。

### 25.6 性能与降档

- 轨道中心半径：`laneR = [0.30, 0.44, 0.58, 0.72, 0.86]·R`；轨道半高 `0.050R`（内两轨 `0.055R`）。
- 五档命名与归属（按 §25.2 weight）：`L0 重载 ≥0.62`、`L1 活跃 ≥0.40`、`L2 常规 ≥0.18`、`L3 轻载 ≥0.06`、`L4 沉积 <0.06`。
- 轨道绘制：每轨两条 1px 边线（alpha .16/.10）+ 中线虚线（alpha .10，每 6° 一短划）+ 轨道标签（`重载 / 活跃 / 常规 / 轻载 / 沉积`，9px mono，置于 12 点方向轨道外侧，alpha .35）。
- 轨道需**一眼可见**：任意静帧中五条轨道与各自的芯片必须可数；芯片不跨轨（仅 ±0.014R 的呼吸抖动）。
- 同轨角度基准 `hash(pid)*TAU`，并按「同轨最小角距 ≥ (芯片宽/半径) × 1.15」做一次常量松弛（布局期算一次，运行期不再抖动）。

### 26.3 芯片：模块而非方块

- 尺寸随权重：`w = 10 + 26*weight`（10–36px）、`h = 5 + 9*weight`（5–14px）；L4 最小，L0 最大；同一轨道内尺寸也有 15% 由 hash 决定，拒绝等大网格感。
- 结构（自外向内）：1px 外框（轨道色，alpha .55）→ CPU 填充条（宽 = `0.6w*cpuPct/100`，色=轨道色，alpha .85）→ 右侧线程刻点（`min(8, ceil(threads/8))` 个 1×h*0.5 竖点，间隔 1px）→ 底边内存带（长 = `w*memN`，1px，冷白 alpha .5）→ 中心亮核 2px（活跃度 ≥0.4 才画，alpha .8）。
- 运行态脉冲：每芯一个解析相位的「数据脉冲」沿长边扫过，周期 `0.8+1.6*(1-weight)` s，扫过处亮度 +25%（不改变位置/尺寸）。
- 尾迹：沿运动反方向 6° 渐隐（宽 = h，alpha .18）。
- 选中：2px 白描边 + 四角刻 + 标签（`名 · 轨道 · PID`）；hover：外扩 1px。

### 26.4 运动：随占用/运行/传输实时变化

- 角速度：`omega = 0.008 + 0.30*weight^1.5` rad/s → L4≈0.008（785s/圈）、L0≈0.28（~22s/圈）；同轨另有 ±2.5% 由 `dataRate` 连续调制（`omega *= 1 + 0.025*sin(t*0.7+hash)`），**禁止随机跳变**。
- 径向呼吸：`r = laneR[band] + (hash-0.5)*0.014R + 0.006R*sin(t*(0.35+0.8*weight)+hash*TAU)`；全部 damp 连续。
- 可见性标准：固定相机、间隔 1.2s 两帧，≥80% 芯片的屏幕位移 >2px；L0 与 L4 的角速度比 ≥12×（QA 断言）。
- 每芯光束（连续，不是离散点）：内指细线，`width = 0.6+1.8*weight`，`alpha = 0.10+0.35*weight`，线上流动 dash（`lineDashOffset` 速度 `60+200*weight` px/s）；叠加脉冲：周期 `0.5+2.2*(1-weight)` s，脉冲瞬间 width ×1.8。
- 数据包：`rate = 3 + 30*weight^0.8` 个/秒（L0≈33/s、L4≈3/s），在途池 ≤1600，恒速 0.55R/s 向内，吞没于 0.14R。
- 入口雨幕与排水渠按 §25.3 保留（220 条 / 24 渠），但亮度降一档（不是主视觉）。

### 26.5 核心：六层数据引擎（替换正八面体）

中心 0–0.28R 全部重构为**连续运转的机械核心**，所有角速度按 `（0.7+0.6*CpuN）` 整体缩放：

1. **L0 进气口 iris**（r 0.045R）：20 片叶片，转速 `+0.55` rad/s，开合半径 `0.040+0.012*CpuN`。
2. **L1 主轴 rotor**（r 0.075R）：八边形骨架 + 8 根辐条 + 8 支活塞（径向伸缩 `sin(t*1.2+φ)`，幅度 0.012R），转速 `+0.30` rad/s；轴心亮核亮度 ∝ 总 CPU。
3. **L2 齿环 gear**（r 0.105R）：48 齿（齿高 0.008R），**反向**转速 `−0.22` rad/s。
4. **L3 涡轮 vanes**（r 0.14R）：12 片弧形叶片，转速 `+0.14` rad/s，叶片间隙透光。
5. **L4 数据涡流**（0.16–0.24R）：48 个螺旋粒子同时向内卷（`dθ=+0.9 rad/s, dr=−0.10R/s`），到 0.16R 消失并回填外圈，颜色=轨道色混白。
6. **L5 散热格栅 + 扫描环**（0.26R）：24 条辐射格栅；每 3s 一道扫描环从 0.02R 匀速扩到 0.30R（300ms），不闪。
- 核心周围 0.28–0.30R 一圈「进气负压」暗环，接地外轨道。
- 所有层必须**各自可见的连续运动**（不同半径不同转速正反交替），静帧下也能看出这是机械而非几何装饰。

### 26.6 性能与降档

- 单帧 ≤8ms（200 进程 / 1440×900 / DPR1.75）；quality<0.85：尾迹与脉冲减半、涡流 48→24；quality<0.7：雨幕关闭、光束只画 L0–L2、涡流关闭。
- 运动全部解析式（时间函数），禁止 `Math.random()` 参与任何逐帧位置/速度/透明度。
