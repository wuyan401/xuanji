## 0. 方法与口径

- 采集:Steam Web API 官方截图 8 张(1920×1080);Fandom 游戏内 UI 截图 5 张(经 wiki 图片 API + Referer 头取得);官方 GDC Showcase 2023 演讲幻灯片 3 张(经 4gamer 一手报道附图取得,原图 1087×608)。
- 测量:同 Stellaris,`palette.py` 量化每图 12 色 + meanLum/meanSat/accentCandidate;关键 UI 面板另做像素级取色、行/列扫描(找线宽、色带、横条高度)。
- **实测优先**:hex、占比、亮度、对比度、线宽/条高均为实测;未实测的 px 尺寸或动效时值标注「目测/推测」。
- 重要提醒:**幻灯片图(cyberpunk_14/15/16)是大面积亮黄,会把 meanLum 拉高到 187/170**,统计时须与游戏画面分开看(见 C3)。

## B. 逐图观察(16 张入选图;构图 / 镜头 / 光照 / 材质 / 元素 / 信息层级)

### B1 `cyberpunk_01_car_ride_night_city.jpg`(1920×1080,meanLum 42.3 / meanSat 60.6)
- **构图:** 车内视角,人物在画面左右两半,前挡风玻璃把「车内暖色」与「城市霓虹」切成两区;画面底部是仪表台暗部。
- **镜头:** 广角近景,轻微鱼眼感;景深极浅,人物清晰、街景散景。
- **光照:** 车内暖琥珀(#212016 12.53%、#1c1603 10.55%、#241703 8.31%)vs 车外青蓝霓虹;高光在额头与玻璃反光。
- **材质:** 皮革/塑料粗糙反射、玻璃水痕、霓虹 bokeh 光斑。
- **元素:** 人物、方向盘、仪表、窗外霓虹与车流。
- **信息层级:** 叙事画面,无 UI;情绪=「夜之城的第一眼」。
- **可迁移点:** 「暖内冷外」的双色温结构;大面积暗部里只放 1–2 个亮点。

### B2 `cyberpunk_02_neon_street_night.jpg`(1920×1080,meanLum 57.9 / meanSat 43.0)
- **构图:** 纵深街道,两侧店面与招牌形成透视导引线;一个人影在中央偏下。
- **镜头:** 人眼高度、中景;雨夜湿地面反射拉长光源。
- **光照:** 红/品红主导(实测 #692e2d 11.30%、#764b4d 10.09%、#4a1f18 9.70%),青色作补光;整体亮度中等偏低。
- **材质:** 湿沥青、金属卷帘门、霓虹灯管、塑料招牌(日文/汉字招牌纹理)。
- **元素:** 霓虹招牌、巷口、行人、路灯、雨。
- **信息层级:** 环境叙事;招牌文字密度高但不要求读。
- **可迁移点:** 低饱和红(#692e2d 量级)+ 亮青补光的「霓虹夜景」组合;我们可借「低饱和底 + 单点高饱和霓虹」。

### B3 `cyberpunk_03_jackie_night_city.jpg`(1920×1080,meanLum 68.2 / meanSat 45.6)
- **构图:** 半身肖像居中,人物占画幅 1/3;背景是城市散景,形成「人像海报」构图。
- **镜头:** 中焦、浅景深、微仰视;人物正对镜头。
- **光照:** 脸颊暖橙主光,衣服黄色+发光青绿线(#8f7d36 7.68%、#2c7462 6.80%),背景青/橙双色散景(#0c4041 13.89%)。
- **材质:** 织物、金属拉链、发光线材;皮肤次表面感。
- **元素:** 人物、夹克发光条、背景霓虹。
- **信息层级:** 人物=唯一主体;发光条是「赛博义体」语义。
- **可迁移点:** 「黑底 + 一处自发光描边」的识别法;可借给 agent 徽记选中态。

### B4 `cyberpunk_04_judy_interior_neon.jpg`(1920×1080,meanLum 30.5 / meanSat 20.2)
- **构图:** 室内中景,人物坐姿偏左下,右上是紫色霓虹招牌;画面被暗部包围。
- **镜头:** 中焦平视,浅景深。
- **光照:** 极暗(实测 #0b0f0d 18.04%、#0a0b0b 14.29%),唯一亮源是紫霓虹(#eb03d3 accent)与屏幕青光;皮肤由环境反射塑形。
- **材质:** 暗房间、布艺沙发、CRT/屏幕、霓虹玻璃管。
- **元素:** 人物、紫色霓虹字、屏幕、杂物。
- **信息层级:** 情绪画面,信息极少;暗部占 80%+。
- **可迁移点:** 「近黑房间里的一盏彩色霓虹」= 最低成本的情绪照明;也印证大面积暗色可行。

### B5 `cyberpunk_05_street_dusk_skyline.jpg`(1920×1080,meanLum 101.7 / meanSat 18.3)
- **构图:** 黄昏街道+远景摩天楼,车与人剪影在下方 1/3;天空占上半。
- **镜头:** 广角平视,大景深。
- **光照:** 低对比冷灰天光(实测 #99afb3 16.49%、#575a56 11.12%、#344240 10.61%),暖色很少(仅尾灯/天空边缘)。
- **材质:** 混凝土、玻璃幕墙、沥青;空气透视(远景发灰)。
- **元素:** 高楼、车流、飞行器、路灯。
- **信息层级:** 环境全貌;用于「世界观展示」而非 UI。
- **可迁移点:** 高亮度低饱和的「日常态」也可与夜间戏共存;对我们而言提示:**深色 UI 不要依赖高饱和照片做背景**。

### B6 `cyberpunk_06_set_vs_appearance_ui.jpg`(1920×1080,meanLum 35.0 / meanSat 36.8)
- **构图:** 角色创建页:顶栏标题「SET V'S APPEARANCE」居中(两侧短横线),左侧超大人物特写(占 60%),右侧一列选项滑杆,底部左右两组快捷键提示。
- **镜头:** 人物为固定机位近景(3D 实时渲染,不是照片)。
- **光照:** 红黑主题:面板底蓝黑(#06090e 5.74%、#05080d 3.33%),人物背后暗红渐晕(#1f0c10 3.30%、#200d11 1.59%);顶部整体被暗红洗过(顶栏区域实测 #2d0f11)。
- **材质:** UI 是纯平色块 + 1px 线,零圆角;选项行 =「标签 + 长横线 + 右值」,选中行下方一道亮线。
- **元素:** 顶部小字「PROTOCOL_60709」类协议编号(左上/左下)、右侧选项(Hairstyle 50 / Hair Color / Eye Color… 带 `<` `>` 角标)、青色高亮(accent #22fcff)、右下键位提示、左下 NIGHT CITY / Resident Database 法务小字。
- **信息层级:** 人物预览(视觉主导)→ 右侧参数(逐项修改)→ 底部键位(操作回忆)。**注意:标题用红字+字距,正文用白/灰,数值用红橙。**
- **实测:** 背景四角取色 #411419(左上暗红)、#160d10、#10070a;选中行高亮处出现 #650300/#4b0200 的红色辉光。
- **可迁移点:** 「左预览 + 右参数列 + 底部键位」的三段式;红黑主题 + 青高亮;轴测式长横线滑杆。

### B7 `cyberpunk_07_braindance_database_items.jpg`(1860×609,meanLum 19.3 / meanSat 10.5)
- **构图:** 黑场图鉴:左侧一件螳螂刀(3/4 视角),右侧两个 BD 卡带盒(橙色),等距排布。
- **镜头:** 产品摄影式正交/略透视,无环境。
- **光照:** **纯黑 35.30%**,物体由 studio 光塑形;唯一高饱和是橙色卡带(#da7108 accent)。
- **材质:** 碳纤维、金属刃、塑料卡带;细致反射与磨损贴花。
- **元素:** 义体武器、BD 卡带、极小标号(编号/品牌字)。
- **信息层级:** 物体即信息,无 UI chrome;收藏/图鉴语义。
- **可迁移点:** 「黑底大物件 + 无边框」的图鉴陈列;我们可以用抽象几何徽记做同类陈列。

### B8 `cyberpunk_08_ripperdoc_database_characters.jpg`(1860×609,meanLum 39.2 / meanSat 13.4)
- **构图:** 四人一字排开,等距,全身/半身;纯黑背景,**纯黑占 31.11%**。
- **镜头:** 平视正面,略低机位;像「角色档案照」。
- **光照:** 顶光+侧光勾轮廓;皮肤与服装低饱和,唯一红点是义体/眼镜(#a51806 accent 暗红)。
- **材质:** 布料、皮革、金属义体、塑料配件。
- **元素:** 四个人物、义体手臂、眼镜、穿孔。
- **信息层级:** 人物身份 > 细节;命名标签不在画面里(靠外部 UI)。
- **可迁移点:** 「黑底等距人物列」作为档案陈列;我们改用 agent 徽记/头像位。

### B9 `cyberpunk_09_loot_hud_perk_shard.jpg`(1920×1080,meanLum 41.2 / meanSat 53.8)
- **构图:** 第一人称 HUD 场景:中央一个发光战利品箱,右下角弹出物品 tooltip,左上是世界内黄黑警示带,右上小地图/任务,右下武器状态。
- **镜头:** FPS 视角(近地面),略有运动模糊。
- **光照:** 环境暗橄榄(#0d1006 13.82%、#151306 11.04%),箱体自发光;tooltip 面板实测 **#0e0e16**(18.38%,蓝黑),标题红≈**#e98c6b / #ef9273**(珊瑚红,不是纯红)。
- **材质:** 塑料箱、金属地面、黄黑警示带(涂装)。
- **元素:** 战利品箱(带格栅与标签)、tooltip(红标题 PERK SHARD / TIER / 效果行)、世界提示「CONTAINS」列表(白字)、交互键提示(白色 key cap + 标签)、敌人红色标记、黄色感叹号、左下义体快捷栏。
- **信息层级:** 世界(第一层)→ 交互高亮(第二层)→ tooltip(第三层);**键位永远贴在动作旁边**。
- **实测:** 黄黑警示带在 1080p 画面里呈 **5–7px 亮带 / 约 20–21px 周期**(受透视压缩,实测 y=150 行的黄色 run);黄带实测 #d9c23a 量级(取色含光照);tooltip 底 #0e0e16。
- **可迁移点:** HUD 角标框 + 键位贴片 + 右侧三段 tooltip;黄黑警示带只做「危险/边界」语义。

### B10 `cyberpunk_10_map_journal_ui.jpg`(1920×1080,meanLum 12.4 / meanSat 20.5 —— 全组最暗)
- **构图:** 全屏地图:近纯黑底(#0b0a08 37.85%),青色路线曲线贯穿,红色标记点散布;顶部一条 tab 栏,左上 FILTER 列,右下指南针与时钟,底部一整行键位提示。
- **镜头:** 正交俯视地图。
- **光照:** 无光照;发光仅路线(实测 #236b7a/#216977 量级,因抗锯齿偏暗)与标记红。
- **材质:** 纯数字界面,无材质。
- **元素:** 顶部 tab(CRAFTING / INVENTORY / MAP / CHARACTER / JOURNAL,图标+文字,激活项下方亮线+角标)、FILTER 列(键帽 [Z] NONE / [X] LEGEND)、任务路线、红色小旗标记、指南针、时间「6:30 AM [???]」、底部键位行(8 组)、左缘竖排条形码纹理。
- **信息层级:** tab 导航 → 地图主体 → 筛选 → 图例/时间 → 键位。**顶栏是唯一「常驻信息带」**。
- **实测:** 顶栏高度 ≈ **77px**(tab 文本带 y≈37–70),顶栏底缘有 **2px 红色细线**(实测 x=960 处 y=76–77 红像素);顶栏底 #0f0e14。
- **可迁移点:** 「近纯黑地图 + 青色路径 + 红色标记 + 2px 红底线顶栏」,这是最贴近 ASTRA 星图/事件地图的一张图。

### B11 `cyberpunk_11_lifepath_selection_ui.jpg`(1920×1080,meanLum 40.5 / meanSat 36.8)
- **构图:** 三张竖版卡片并排(三选一),顶部居中「V'S LIFEPATH」+ 小图标,副标题两行;每张卡=海报图+标题+正文;底部左角日期/编号字样,右缘竖排条形码。
- **镜头:** 卡片是独立插画/海报框,不是 3D 视角。
- **光照:** 暗红黑底(实测 #34141a 16.95% 暗酒红 + #060e14 12.60% 蓝黑),卡片内是暖色插画;整体像「红色打光的档案室」。
- **材质:** 卡片无材质,边框=细红线;正文是纯文字。
- **元素:** 卡片边框(细红线 + 角标)、标题(Nomad / Streetkid / Corpo,大写红字)、正文 3 行小字(红橙 #e67376 / #da7c7d 实测)、顶部标题区(背景 #35161b)、底部左下「NIGHT CITY … 23 OCT 2077 / 01299-660」、右缘刻度条。
- **信息层级:** 标题(大字距红)→ 图(情绪)→ 正文(说明)→ 底缘元数据(世界观细节)。
- **实测:** 正文字色 **#e67376 / #da7c7d**(珊瑚红,非纯红);标题区暗酒红 #35161b;整体 meanSat 36.8(低饱和红)。
- **可迁移点:** 「三选一卡片 + 细红线框 + 低饱和珊瑚红正文」;元数据装饰(日期/编号)可借作风味而不抢信息。

### B12 `cyberpunk_12_new_game_mode_ui.jpg`(1920×1080,meanLum 46.1 / meanSat 33.8)
- **构图:** 居中一张 16:9 横图卡,上方居中大标题「NEW GAME」+ 六边形小图标;图卡下方两行说明;最下两枚大按钮(Regular Start / Skip Ahead…);底部中央条形码、右下键位提示。
- **镜头:** 图片是游戏内截图(城市+车+人),UI 是平面模板。
- **光照:** 蓝黑底(#060c12 18.56%、#06090e 15.31%),按钮为 1px 红描边、内部透明。
- **材质:** 纯平面;按钮有轻微暗红填充。
- **元素:** 面包屑标题、图片卡(红描边?实测偏冷白边)、正文白/灰、两枚按钮、底部条形码(0010 8562 9862…)、右缘斜切装饰。
- **信息层级:** 标题→图→说明→按钮;典型的「确认页」。
- **实测:** 底色 #060c12;按钮描边红、字全大写+字距;底部条形码为装饰性等宽数字。
- **可迁移点:** 「确认/选择页」的模板:居中标题 + 图卡 + 说明 + 等宽两按钮 + 装饰性元数据条。

### B13 `cyberpunk_13_nightcity_database_panorama.jpg`(1860×609,meanLum 49.2 / meanSat 23.2)
- **构图:** 宽幅城市天际线全景(图鉴条目),底部一层 UI 说明带。
- **镜头:** 广角高机位,远距离空气透视。
- **光照:** 暖棕+青灰(实测 #30221a 11.15%、#252f31 10.33%、#403126 9.64%),黄昏/清晨。
- **材质:** 建筑混凝土、玻璃、雾霾。
- **元素:** 高楼群、河/桥、雾;无 HUD(图鉴展示态)。
- **信息层级:** 图像 > 说明;用于世界观阅读。
- **可迁移点:** 「宽幅档案图 + 底部说明条」;我们可做「观测快照」。

### B14 `cyberpunk_14_gdc_ui_framework_slide.jpg`(1087×608,meanLum 48.4 / meanSat 12.8)

### C3 亮度/饱和度画像

- 游戏画面 8 张 meanLum 12.4–101.7,中位 ≈ 43;UI 类 6 张 meanLum 12.4–46.1(地图最暗 12.4,角色创建最亮 46.1);**幻灯片 3 张 meanLum 48.4/169.7/187.1**,黄色为主。
- meanSat:夜景类 36–61(霓虹带来高饱和),地图/菜单 13–37;幻灯片 12.8/86.4/95.2。
- 即:**游戏画面靠「暗底 + 少量高饱和霓虹」,UI 靠「暗底 + 低饱和 + 黄/红小面积」**。如果只统计游戏画面(排除幻灯片),黑(#0c0c0c)占比会更高、黄占比更低。

### C4 配色用途逻辑(可写成 token 规则)
1. 黑是默认态:所有面板、地图、全屏页都先铺黑,再放信息。
2. 黄=警告/标题/焦点,且**永远高对比**(黄对黑 14.9:1);黄不做大面积背景(游戏内),只有品牌物料与幻灯片才铺满。
3. 青=「可扫描/可交互/信息路径」;红=「危险/敌意/过载」。
4. 红字用珊瑚红(#e67376 量级)不用纯红(#ff0000):实测提示这是可读性与压暗的平衡。
5. 允许一屏两色系(红黑主题 / 黄黑主题 / 青黑主题)存在,**但每屏只有一个主色相**。

## D. 字体与排版

### D1 字体族(已确证)

| 层级 | 字体 | 证据 | 可信度 |
|---|---|---|---|
| 游戏内 UI(绝大多数) | **Rajdhani**(Regular / Medium / Semi-Bold / Bold 四个字重) | Fonts In Use(A6):「Most the entire in-game user interface is set in Rajdhani」 | 已确证(研究级来源) |
| 次要文字 | **Orbitron**(non-important text) | 同上 | 已确证 |
| 官网标题 | **Refinery**(标题)+ **Blender**(标题与长文) | 同上 | 已确证 |
| 世界观内字体 | Blender / Rajdhani / Orbitron 被用作 diegetic 字体(出现在游戏世界里的屏幕与全息投影) | 同上 | 已确证 |
| 中文 | 官方本地化字体(未公开细节) | — | 推测 |

> Rajdhani 与 Orbitron 均为 OFL(可商用);Blender/Refinery 为商业字体,**不可用于我们的产品**。

### D2 排版特征(从实测截图归纳)

- **全大写 + 大字距**是主语言:tab 标签(「CRAFTING」「INVENTORY」)、按钮(「REGULAR START」)、表头(「PRESETS」「CUSTOMIZE YOUR LOOK」)全部大写,字距目测 **+0.06~0.12em**。
- **方角几何**:Rajdhani 本身是方肩、窄字面;UI 里几乎不用斜体/手写体。
- **字号阶梯小**:tab ≈ 13–14px、正文 ≈ 12–14px、标题 ≈ 20–26px、装饰小字 ≈ 9–10px(按 1920 截图**目测**)。
- **数值与标签分离**:右对齐数值 + 左侧标签(如 Hairstyle `50`);数值常带红/黄高亮。
- **装饰性等宽元素**:条形码(0010 8562 9862…)、日期「23 OCT 2077」、编号「01299-660」,用等宽/紧凑数字;这类「世界观元数据」增强真实感但不承载操作信息。
- **键位语言**:key cap = 方框 1px 边 + 字母居中(如 [Z] [X] [F] [R]),与动作标签成对出现;这是 CP2077 HUD 最可借的组件之一。
- **中英混排(推测,用于 ASTRA)**:Rajdhani 无中文;若中文界面,建议中文用思源黑体/Noto Sans SC Medium,数字与英文标签用 Rajdhani 类方肩字体做混排,**中文 13px 配英文 12px、英文大写标签字距 +0.08em**,避免中文也加字距(会散)。

## E. UI 信息架构解剖(机制层)

### E1 区域与网格(实测自截图)
- **顶栏(77px 高,含 2px 红底线)**:icon+文字的 tab 行,激活项=亮线+小三角/角标;这是常驻导航。
- **左侧筛选列**(地图页):键帽 + 筛选项([Z] NONE / [X] LEGEND),占宽约 1/8。
- **中央主区**:地图/3D 预览/列表主体。
- **右侧详情区**(HUD/物品/选项):tooltip、参数面板、任务提示,宽度按内容浮动。
- **底部键位行**:一整行等距键位提示(8 组),居中对齐;这是「操作可发现性」的系统化设计。
- **边缘装饰**:裁切角标(┌ ┐ └ ┘ 式细线)、左右竖排条形码、顶部红细线、扫描线纹理。**它们不承载信息,只定义「界面边界」**。

### E2 边框、切角、按钮
- 主边框=**1px 细线**(红/白/青),配合**45° 切角**与角标;无圆角、无投影。
- 按钮=透明底 + 1px 描边 + 全大写文字;hover/active 用红色填充或红色辉光(实测选中行出现 #650300/#4b0200)。
- 面板背景常是**半透明深色**(tooltip 实测 #0e0e16 覆盖在场景上),不是纯黑。
- 分割用「线段 + 短标签」,不用卡片阴影。

### E3 图标语言
- 线性图标(1–2px 描边,白色/红/黄),尺寸小(目测 14–18px),与文字同级排布。
- **键帽**是独立组件语言:方框+字母,几乎每个动作旁都有。
- 数据图标(义体、武器、任务)偏「设备示意图」风格,不是拟物插画(区别于 Stellaris 的金属徽章)。
- 状态点/角标:红色小方块/小旗标记地图兴趣点;黄色感叹号标记可交互。

### E4 数据可视化形式
- **路线/路径**:青色曲线(实测 #236b7a 量级)+ 红色标记点;无坐标网格。
- **地图**:近纯黑底,只显路线、标记、区域轮廓;信息密度低但方向感强。
- **进度/状态**:分段条(如 107/280 生命/负重)、数字+斜杠、时间「6:30 AM [???]」。
- **tooltip 三段式**:标题(红)→ 属性(TIER/type)→ 效果/说明(白/黄)。
- **图鉴/档案**:黑底大图 + 无 chrome,信息靠外部列表。
- **装饰性元数据**:条形码、日期、编号(RGN/ID),用于建立真实感。

### E5 状态语言(实测)
- 红=敌意/危险/受损;亮红用于当前焦点(描边/标题),暗红用于底/辉光。
- 黄=警示/目标/可交互;游戏内以 #fdb505 量级出现。
- 青=信息路径/可扫描;扫描模式下万物描青边。
- 白/灰=中性文本;绿色在 CP2077 里较少(更多是黄/红/青)。
- 「过载/入侵」场景:红+白高频闪烁 + 扫描线 + 抖动(来自 F 节观察到的高频警告语言,具体帧率不可测,标注推测)。

## F. 动效与转场语言

### F1 已确证的事实(来自官方 GDC 演讲)
- UI 框架 **INK** 自 2017-04 研发并嵌入 REDengine;2017-06 最小可用、2017-12 完整可运行。
- 体量:嵌入视频 **584 个 / 超 10GB**;UI 贴图、组件库、组件图集各**超 1000 个文件**;UI CPU 内存 **40MB→55MB**(字体导致)。
- 6 大优化领域:①UI 实例分组(最重要)②降低 UI 更新频率 ③降低动画更新频率 ④UI 实例选配(把全城广告当 UI 层)⑤更新与绘制差异(offscreen layer:物品栏图标/全球 TV 频道)⑥3D 世界 UI 的 **HLOD**(2019-09 广告/路牌 render target 碎片化,自建 render target manager)。
- **Active / Passive 模式**:Active=UI 大概可见,全部逻辑执行;Passive=UI 不可见,只执行关键逻辑;每层可自定义。

### F2 观感语言(截图+推断,标注推测)
- **扫描模式(scan)**:世界被施加青边/网格/数据标签层,原生镜头不切换——这是「同一世界、叠加数据层」的动效语法。
- **Braindance**:时间轴擦洗(scrub)+ 图层开关(视觉/音频/热感),画面有颗粒/色偏/故障帧。
- **故障转场(glitch)**:面板开场/切换时出现 RGB 分离、水平位移、扫描线;强度短促(推测 0.15–0.35s)。
- **HUD 呼吸/脉冲**:红色警报、任务更新用低频脉冲,不做满屏闪烁(否则不可玩)。
- **菜单进出**:快速淡入+轻微位移(推测 ≤0.2s),无弹性曲线。

### F3 对 ASTRA 的启示
- 照搬「active/passive」思想做**刷新预算分层**:可见面板 60fps 更新,不可见面板只跑聚合/告警逻辑;这正是常驻监控界面最需要的。
- 借「扫描层」做**数据叠加**:星图上叠加 token/延迟/错误层,而不是切换页面。
- 借「故障转场」做**状态切换提示**(agent 重启/模型切换),但必须提供 reduced-motion 降级(改为静态描边/颜色变化),避免常驻界面持续 glitch 造成阅读疲劳与光敏风险。
- 不借:全屏 TV 噪音、剧烈色偏、随机闪帧、满屏扫描线(这些是游戏皮且有害可读性)。

## G. 可迁移机制 vs 禁止照搬的皮

| 维度 | ✅ 可迁移机制(机制层) | ❌ 禁止照搬的皮(资产/皮肤层) |
|---|---|---|
| 配色 | 黑(占比≥55%)+ 黄(5–15%)+ 青/红功能色的双色系统 | CP2077 的黄 logo、具体黄值 #eee501/#fdb505 原样照搬 |
| 警示带 | 黄黑 45° 斜带 = 「危险/边界」语义;实测 5–7px 亮带/20–21px 周期(透视下) | 具体的涂装贴图、磨损纹理、hazard tape 素材 |
| 顶栏 | 77px 高 + 2px 红底线 + icon+文字 tab + 激活角标 | 具体 tab 图标(工艺/物品/地图…)与中英文案 |
| 边框 | 1px 细线 + 45° 切角 + 角标 + 半透明底 | 扫描线贴图、条码装饰的具体图形 |
| 键位 | key cap 方框组件、动作旁贴键位 | 具体键位(SQUARE/CIRCLE 等主机键)图形 |
| 扫描模式 | 「同一世界叠加数据层」的交互模型 | 具体扫描描边样式、义体 HUD 皮肤 |
| 状态色 | 亮红文字/暗红底、黄警示、青信息路径 | 具体红色警告图标与故障帧素材 |
| 动效 | active/passive 刷新分层、低频脉冲、可降级 | glitch/扫描线/噪点全屏动画 |

| 装饰 | 裁切角标、元数据条(日期/编号)的「世界观真实感」手法 | 条形码的具体图形、夜之城文字与海报 |

**一句话:** 借它的「**黑黄双色 + 1px 切角边框 + 键位系统 + 扫描层 + 刷新分层**」,不借「**霓虹城市照片、故障帧、字体皮肤、具体警示带贴图**」。

## H. 3 条可直接落地的设计规则(来自实测)

### H1 「黑底 + 黄警示带 + 2px 细线」的告警规则
- 画布底 `#0a0a0a`(实测游戏黑 `#0c0c0c` 占比 42.17%);面板底 `#0e0e16`(tooltip 实测 18.38%)~`#0f0e14`(顶栏实测)。
- 品牌黄:常驻/强调用 **`#fce40c`**(实测幻灯片黄族中位;对黑对比 **≈14.9:1**),告警填充用 `#fdb505`(游戏内霓虹黄)。黄色**只做描边/文字/斜带**,不做大面积底(除品牌物料)。
- 警示带几何:45° 斜带,**亮带 5–7px、周期 20–21px**(1080p 透视下实测),仅用于「越界/危险/不可进入」区域;常驻界面中警示带面积 ≤ 屏幕 3%。
- 细线:边框/分隔一律 **1px**;顶栏下缘用 **2px** 强调线(实测 y=76–77);切角 45°、4–8px,不用圆角。

### H2 「珊瑚红文字 + 暗红底」的可读性规则
- 危险文字不要纯红:用实测珊瑚红 **`#e67376`**(lifepath 正文实测)或 `#ff6b5e` 量级;对 `#0a0a0a` 对比 ≈ **6.2:1**(以 #ff5252 实测参照,满足 WCAG AA 正文 4.5:1)。
- 暗红只做底/辉光:`#a51806` 对 `#0a0a0a` 仅 **2.58:1**(实测),绝不能用于正文;它的用途是危险区域填充/选中辉光(#650300 量级)。
- 青色信息态:`#00d2a2` 对 `#070908` = **10.21:1**;`#22fcff` 量级更高,可用于强调但面积 ≤2%。
- 灰字:`#8c94a0` 对近黑 = **6.52:1**(实测),可作次要标签;更低对比的装饰元数据可用 40–50% 透明度(推测阈值,需设计阶段校准)。

### H3 「77px 顶栏 + 键位贴片 + 三段 tooltip」的组件规则
- 顶栏:高 **77px**、底缘 **2px 红/黄细线**、tab 内容垂直居中(y≈37–70);tab=图标 16px + 大写标签 13px、字距 +0.08em、激活项带 2px 亮线。
- 键位组件:key cap = **18×18px** 方框(目测)、1px 边、字母 11px 居中;动作标签 12px 紧随其后,间隔 6px;底部提示行居中、组间距 24px(目测)。
- tooltip 三段式:标题(13px 大写、红/黄)+ 属性行(11px 灰)+ 效果列表(12px 白、缩进 12px);面板底 = `#0e0e16` @ 92% 不透明度(实测面板接近实心,推测 90–95%),1px 边 + 角标。

## I. 与 ASTRA 观测台的关联(四类界面映射)

### I1 星图 / 星座(会话与 agent 的关系图)
- 借:地图页的「近纯黑底 + 青色路径 + 红色兴趣点 + 2px 红底线顶栏」;节点=我们的 agent 徽记,路径=事件流/调用链。
- 借:扫描模式——同一张图叠加「延迟层/错误层/token 层」,用图层开关而非换页。
- 借:顶栏 tab 导航(星图/仪表盘/账本/告警)与过滤列(键位筛选思路改为下拉/快捷键)。
- 不借:夜之城鸟瞰照片、CP2077 地图图标与地名。

### I2 仪表盘(全局状态)
- 借:HUD 角标框——四角裁切标记界定「观测区」;中心是数据,而不是卡片墙。
- 借:键位贴片(把快捷操作贴在动作旁)与底部整行键位提示,提升可发现性。
- 借:黄=警示阈值、青=健康信息、红=越界;分段条表达配额(如 token 预算/并发数)。
- 借:77px 顶栏 + 2px 强调线,作为全局状态带的骨架。

### I3 事件账本(账本/时间线)
- 借:图鉴陈列(黑底大物件、无 chrome)做单条事件详情;列表用 Rajdhani 类方肩字体 + 大写标签。
- 借:lifepath 三卡片式做「候选方案/重试策略」三选一;细红线框 + 珊瑚红正文。
- 借:元数据装饰(时间戳、编号、条形码)表达「观测记录」的真实感——但用我们自己的编码规则。
- 借:tooltip 三段式(事件/属性/影响)。

### I4 告警(过载/异常)
- 借:黄黑警示带语义(越界区),但面积受控(≤3%);红字用珊瑚红保证可读。
- 借:「红色过载」= 暗红底 + 亮红描边 + 低频脉冲(0.5–1Hz,推测;提供 reduced-motion 静态态)。
- 借:active/passive 分层——告警面板永远 active,后台图表 passive,降低常驻开销。
- 不借:全屏 glitch/噪点/TV 雪花;警报声(若需要,另行设计且可关闭)。

### I5 对最终产品的硬约束(交给 lead)
1. 黄黑警示带与切角边框可以用,但必须重新绘制,不得使用 CP2077 的贴图/图标/字体皮肤。
2. 字体只用 OFL 字体(Rajdhani/Orbitron 可直接用;Blender/Refinery 禁用);中文需配套 CJK 字体并统一字面率。
3. glitch/扫描线等动态效果必须提供 reduced-motion 降级,常驻界面默认关闭高频动效。
4. 黑/黄/青/红四色分工必须固定:黄=警示/焦点、青=信息/可交互、红=危险/过载、黑=默认底;禁止语义复用。
5. 与 Stellaris 参考系合并时:CP2077 提供「高对比边框与 HUD 语言」,Stellaris 提供「低饱和星图与三色状态」——两者不能同时定为主基调,建议以 Stellaris 的深色为底、CP2077 的黄/红作为告警层(此建议供 lead 决策,不作定论)。
