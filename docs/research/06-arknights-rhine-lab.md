# 06 · 明日方舟「莱茵生命」视觉参考系实测报告

> **调研对象**：Hypergryph《明日方舟》中的科研机构「莱茵生命（Rhine Lab）」视觉系统——游戏内实验室场景背景 CG（7 张）、莱茵生命总部美术与官方壁纸（4 张）、NPC 概念设定页（官方美术设定集内页）、档案/卷宗界面（Project Diabolic Files）、孤星（Lone Trail）活动主视觉 banner。
> **目的**：为「ASTRA 观测台」提取**"临床理性 / 科研档案 / 洁净感"** 的可迁移机制。只借机制，不复制皮肤；最终产品自绘。
> **方法**：① 从 `arknights.wiki.gg`（无防盗链，直连可用）下载 16 张官方图；② `tools/palette.py` 量化 12 色；③ `tools/contact_sheet.py` 拼图；④ `read_image` 逐张看图，并对 `rhine_13`（官方设定集内页）与 `rhine_09`（官方壁纸）做标尺测量。
> **证据等级**：`【实测】`＝量化或标尺测量；`【目视】`＝看图可确认；`【推测】`＝反推，需二次验证。
> **采集日期**：2026-10-25。**报告日期**：2026-10-27。**撰写**：拾汐·Seasum（teammate `style-mythic`，task-3）。
> **⚠ 版权**：全部图像版权归 Hypergryph / 鹰角网络 所有，仅作仓库内研究凭证，不得进入最终构建、不得再分发。莱茵生命 / Rhine Lab 字标、角色形象（Saria、Muelsyse、Dorothy 等）、孤星活动美术一律不得出现在产品中。
> **⚠ 本报告最重要的一条反直觉发现**：**莱茵生命的"洁净感"不是靠冷蓝科幻色实现的。** 7 张游戏内场景的高光色调其实是**低饱和橄榄/卡其暖灰**（`#848266`、`#908e72`、`#9c9067`），饱和度只有 **9.2%–25.3%**，色相集中在 **40°–60°（黄绿）**；冷蓝灰（`#83929d`、`#91a5b4`）只出现在**建筑外景与概念图**里；真正制造"洁净"的是**高明度（meanLum 133–176）+ 极低饱和 + 少量冷白荧光高光（`#dfe9ec`，色相 194°）**。这条如果搞反，做出来就会是"廉价科幻实验室"，而不是莱茵生命。

## 0 结论摘要（先读这段）

1. **洁净感 = 高明度 × 极低饱和 × 冷白高光点缀，与蓝色无关。** 7 张场景实测：`meanLum` 79.4–175.6，`meanSat` 9.2%–25.3%；主色全是 `#848266` / `#908e72` / `#9c9067` / `#bdb18b` 这类**暖灰橄榄卡其**；唯一"冷"的是少量冷白高光 `#dfe9ec`（9.0%，色相 193.8°）与窗外的冷蓝灰【实测】。→ 我们做仪表盘若想"临床"，应该是**暖白纸 + 冷白荧光 + 一点橙**，不是"深蓝 + 青色发光"。
2. **颜色的职能非常明确：橙 = 实验/警示，青 = 医疗，红 = 安保，灰 = 文职，无穷=机构。** 官方设定集内页（`rhine_13`）底部有一排**方块单字母标签**（∞ / C / R / M / S），每块下方标注中文职能——这是现成的"角色/职能图例"范式，可直接迁移成 agent 状态图例【目视+标尺】。
3. **官方设定集内页（`rhine_13`）是本参考系里最有价值的信息设计样本**：1280×1719 的白纸页，含页码、页眉标签+大标题+右元数据、通栏细线、4–6 列等高人像网格、每组下方 12px 居中说明、组间 1px 橙色通栏分隔线、图号斜体、角色职能图例、脚注与版权行。**一页之内把"档案"的结构讲完了**。
4. **灰度 = 归档。** 档案界面 `rhine_14`（Project Diabolic Files）实测 `meanSat 0.0%`——**纯灰度，零彩色**；画面由红章（CLASSIFIED）、红色遮挡条、白纸、黑边框、漫画分镜构成。→ 我们做"已归档/已结束"的历史事件，应当**整块去彩**，而不是加一层灰罩。
5. **"警告条纹"在莱茵生命里是低频、细、低对比的**：官方壁纸 `rhine_09` 地面有编码刻度（`1 2 3 4 5 6` 交替黑/藏青/橙）、一条细的斜纹警示带、以及一个**小小的深色卡片 + 琥珀色图标 + 等宽倒计时 `???23:59:09`**。→ 警示元素是"点缀在洁净环境里的一点点工业性"，不是满屏黄黑警戒线。
6. **可迁移度最高的 3 个机制**：① 高明度低饱和中性纸 + 冷白荧光 + 单橙强调（三色系统）；② 档案页结构（页眉/通栏细线/分组/橙分隔/图号/脚注/页码）；③ 方块单字母职能图例（chip 系统）。
7. **必须避开的皮**：莱茵生命 logo 与 R 标、角色立绘与姓名、孤星活动美术与"LONETRAIL 孤星"字标、橙黑警示条纹的具体比例（会直接撞上"危险"语义）、把"临床"做成冷蓝科幻、以及"白大褂/实验室道具"的具象 skin。

## B 逐图观察

### B.1 游戏内场景 CG（7 张，最贴"临床空间"的样本）

**01 · 实验室（Laboratory）** — 构图：高机位广角俯视，前景是实验台与玻璃隔断，中景是开放办公区，远处有窗与绿植。镜头：略俯，透视柔和（无明显灭点压迫）。光照：**室内荧光为主，色温偏暖**（主色 `#848266` / `#908e72`，`meanSat 16.0%`、`meanLum 98.6`【实测】）；阴影不深，整体低对比。材质：磨砂玻璃、浅色台面、灰绿地板、布面隔断。元素：显示器、仪器、植物、白板。信息层级：前景台面 → 中景人群区 → 远景窗光。**"洁净"来自"没有一处颜色是饱和的"，不是来自白。**

**02 · 总部控制室（HQ Control Office）** — 构图：对称的圆形中庭，中央有浅色水景/装置，四周是弧形办公台；顶部灯带形成环形光。光照：**高明度（`meanLum 175.6`）**，主色是米卡其 `#9c9067` 12.8% / `#bdb18b` 11.1% / `#ccc2a3` 10.0%，但出现唯一冷色高光 `#dfe9ec` 9.0%（色相 193.8°）——来自窗与灯带的冷白【实测】。材质：浅石、白金属、玻璃、浅色织物。层级：中心装置 > 环形台 > 顶部灯带。**这是"控制室"最值得抄的一张：暖白空间 + 一道冷白光。**

**03 · 走廊（Corridor）** — 构图：**一点透视长走廊**，尽头是一扇极亮的白光门（过曝）。光照：近暗远亮，尽头光晕极强（`#fcfbfa` 6.4%），墙面近中性灰棕（`#6f6c65` / `#58544d`），整体 `meanSat 9.8%`【实测】。材质：磨砂墙板、深色地面、灯带。层级：**亮度即纵深**——越远越白。**"通向未知/通向核心"的最省成本构图：一条走廊 + 尽头过曝。**

**04 · 走廊 B** — 与 03 同构，玻璃门更多、层次更平（`meanSat 9.3%`）。

**05 · 总部（HQ 内部/远景）** — 构图：白灰空间 + 大面积玻璃 + 绿植，主色 `#c1c1c1` 11.9% + `#91948b` 9.6%，`meanSat 9.2%`。**几乎无彩色的一张：证明"洁净"可以是纯灰。**

**06 · 会议室（Meeting Room）** — 构图：弧形玻璃会议舱内部，圆桌居中。光照：暗木 + 卡其（`#3d3629` 15.4%、`#6e6756` 11.1%），`meanLum 98.2`、`meanSat 16.7%`。材质：木饰面、皮革、玻璃。**"高级感"来自材质（木/皮/玻璃）而不是颜色。**

**07 · 观测站（Observation Post）** — 构图：室内大玻璃窗前，前景座椅与桌面。光照：暗橄榄主调（`#14120a` 13.9%、`#7d7255` 10.6%），`meanLum 79.4`，唯一亮区是窗外。材质：木、金属、织物。**"观测"场景：室内压暗，窗外亮。**

| 层 | 色 | 实测出处 | 用途逻辑 |
|---|---|---|---|
| **纸白 / 空间亮部** | `#f7f6f0`、`#fbfbf3`、`#f7f2ef`、`#fffffe` | 13（合并 ≈ 49%）、09（17.1%）、10 | 内容承载层；"洁净"的物理载体 |

**配色用途逻辑（为什么这套看起来"科学"）**：
- **低饱和 = 没有情绪**：全部场景 `meanSat ≤ 25%`，其中 4 张 ≤ 10%。低饱和把画面从"故事"拉向"记录"。
- **高明度 = 秩序**：控制室 175.6、壁纸 206.6、设定集 226.0——**越接近纸白，越像"资料"而不是"场景"**。
- **冷白高光 = 荧光灯 = 机构感**：`#dfe9ec` 只在窗/灯带出现，它是"有人维护这栋楼"的唯一证据。没有它，暖灰会变成"旧"；有了它，暖灰变成"干净"。
- **橙 = 唯一被允许的色彩**：它同时承担"图例色块、分隔线、警示条纹、实验图标"，面积始终 ≤ 3%。→ **单强调色系统（mono-accent）是最省成本、也最容易维持一致性的做法。**
- **蓝 = 外部**：冷蓝灰只在建筑外景/概念图/天空。→ **不要把蓝色放进室内界面。**

## D 字体与排版

### D.1 可确证的事实（主要来自 `rhine_13` 设定集内页与 `15/16` banner）

1. **中文标题用粗黑体（无衬线）**：`绿野幻梦` 约 30px、笔画粗、字面方正；`孤星` 两个大字更粗更大（约 120px @1560 宽 banner）【目视】。
2. **拉丁文字全部是中性 grotesque**：`CONCEPT ART`、`EVENT`、`PROJECT DIABOLIC`、`LONETRAIL` 都是无衬线、字距略开（约 +0.04~+0.08em）；没有任何衬线体出现【目视】。→ **这条很重要：莱茵生命是"无衬线机构"，星铁是"衬线神话"。两者气质差异有字体层的原因。**
3. **层级靠"字号 + 灰度 + 细线"实现**：页码 14px / 页眉 13px / 大标题 30px / 组说明 12px / 图号 11px 斜体 / 脚注 11px / 版权 9px；同屏 7 级，但只有 2 种字色（近黑 `#2b2a27`、中灰 `#6b6a63`）【实测估算】。

5. **斜体只用于图号/注释**（`图.03`、部分拉丁副标），正文不用斜体。
6. **细线是结构本身**：页眉下的 2px 黑线、`NPC` 上方的 1px 线、组间的 1px 橙线、banner 底部的 1px 白线——**所有分组都靠线，不靠留白或色块**。
7. **表格/说明用"小字居中"**：每组人像下方的职能说明是居中的 12px 灰字，不加粗、不加框。

## F 动效与转场语言

> ⚠ 无录屏证据，以下为**基于静态图的工艺推断**，全部 `【推测】`，需实机验证。

1. **档案展开**`【推测】`：卷宗/抽屉的入场是"从上方滑出 + 轻微旋转 1–2°"，时长 **240–280ms**，ease-out（`cubic-bezier(0.2, 0.8, 0.2, 1)`）；落位后 80ms 内出一条 1px 橙线从左到右画出（`stroke-dashoffset` 180ms）。
2. **临床节拍**`【推测】`：所有过渡以 **160–280ms、ease-out** 为主；**禁止回弹（overshoot）与弹簧**——这是"理性"与"活泼"的分界线。星光/星铁可以有回弹，莱茵生命不行。
3. **扫描/检定**`【推测】`：从左到右的水平细线扫过（1px，`rgba(0,0,0,0.15)`），周期 1 次 600ms；配合数据"落位"（数字快速滚动 300ms 后停）。
4. **警示条纹**`【推测】`：斜纹带缓慢平移（速度约 8–12px/s，周期 8s），**只在告警态出现**；不闪烁。
5. **蓝图/图纸显影**`【推测】`：分四层依次出现——① 背景网格（opacity 0→1，200ms）→ ② 结构细线描边（700ms）→ ③ 填充/色块（300ms）→ ④ 标注与图号（200ms，逐个出现）。总计 **1.2–1.4s**，非常适合作为"扫描完成/数据就绪"的揭示动画。
6. **光标与数字**`【推测】`：输入光标闪烁 1s 周期（硬切，不做渐隐）；数字刷新用等宽 + 滚动，避免抖动。
7. **禁止项**：不要用 glitch、不要用霓虹发光、不要用弹跳、不要用"能量脉冲"——莱茵生命的动效应当像"仪器在工作"，安静、精准、有节奏。

## H 3 条可直接落地的设计规则

### H-1 三色系统：纸白底 80% / 暖灰结构 15% / 冷白荧光 5% + 单橙 ≤ 3%

- **依据**：7 张场景 `meanLum 79.4–175.6`、`meanSat 9.2%–25.3%`；设定集内页 `meanLum 226.0`（纸白占 49%）；控制室的冷白高光 `#dfe9ec` 占 9.0%，但**只在灯带/窗**；橙色在所有图里目视 ≤ 3%【实测+目视】。
- **落法**（建议值）：
  - `--paper: #faf9f5`（底，≥ 70% 面积）
  - `--panel: #efeee7`（面板，≈ 15%）
  - `--card: #ffffff`（卡片/浮层）
  - `--line: #d8d5cc`（1px 结构线）
  - `--text: #2b2a26`；`--muted: #6b6a63`
  - `--fluor: #e4eef0`（冷白荧光，仅用于高光带/选中态，≈ 5%）
  - `--accent: #d0743c`（唯一强调色，**≤ 3%**）
- **验收**：`palette.py` 应显示"近白族 ≥ 45%、`meanSat` ≤ 15%（纯环境）、accent 不进入前 3 主色"。

### H-2 数据表：表头 11px/+0.06em、行高 32px、1px 横线 @10%、数字等宽右对齐

- **依据**：设定集内页 7 级字号（9/11/12/13/14/30px）+ 只两种字色；全篇无竖线、无斑马纹；页码与倒计时为等宽数字【实测估算+目视】。
- **落法**：`thead th { font-size: 11px; letter-spacing: .06em; color: var(--muted); font-weight: 500; }`；`tbody td { height: 32px; border-bottom: 1px solid rgba(0,0,0,.10); }`；数值列 `text-align:right; font-variant-numeric: tabular-nums;`；分组用一条 `border-top: 1px solid var(--accent)`（每组仅 1 条）。
- **禁忌**：不要竖线、不要斑马纹、不要卡片化每一行（档案感来自"连续的一页"，不是"一堆卡片"）。

### H-3 状态图例 chip：34×34、圆角 2px、单字母 16px、下挂 11px 标签，最多 6 色

- **依据**：`rhine_13` 左下角实测 34×34、圆角约 2px、单字母居中、下方 11px 中文；色数 5（黑/灰/橙/青/红）【实测估算】。
- **落法**：`width:34px;height:34px;border-radius:2px;display:grid;place-items:center;font:600 16px/1 var(--mono);color:#fff;`，下方 `font-size:11px;letter-spacing:.04em;color:var(--muted)`；状态色最多 6 个（本机、运行中、健康、告警、异常、归档）。
- **禁忌**：chip 内不要放图标（字母识别率更高、更"机构"）；圆角不要超过 4px（圆角一大就变"App 按钮"）。

## I 与 ASTRA 产品的关联

### I.1 仪表盘 → 临床数据表（最强映射）

- **底色用纸白**（`#faf9f5`）、结构线 1px 浅灰、数值等宽右对齐、表头 11px 灰——这就是"临床感"的全部。
- **不要用深色仪表盘 + 霓虹数字**（那是 ZZZ 的语言，不是莱茵的）。若 ASTRA 需要暗色主题，正确做法是**保留同一套纸白/墨色的层级关系，只把明暗反过来**（纸→近黑、墨→米白），而不是引入蓝光。
- 每条 agent 数据一行，行高 32px；分组用橙色细线（每组 1 条）；异常行只在**数值**上做处理（橙色数字 + 一个 chip），不整行变红。

### I.2 事件账本 → 档案页/卷宗

- 一条事件 = 一张"档案条目"：页眉（时间戳 + 事件类型标签 + 页码式序号）→ 通栏细线 → 正文 → 组说明式元数据（12px 灰、居中或右对齐）→ 底部一条橙线（仅当需要分组时）。
- **已结束/已归档的事件整块去彩**（`filter: grayscale(1)`），未结束的保留彩色——这就是莱茵生命"灰度=归档"的直接映射。
- 图号用斜体等宽（`#00012`），页码感来自"这是第 N 条记录，不是第 N 个卡片"。

### I.3 告警 → 橙单色 + 细条纹（仅告警态）

- **警告级**：橙色（`--accent`）数字/小 chip + 1px 橙线，**不整屏变红**。
- **严重级**才允许：细斜纹带（高 20px、低对比、缓慢平移）+ 一个红色 chip；**永远不用满屏黄黑警戒线**（原图里警示条纹是极窄、低对比的）。
- 若需要"持续告警"的暗示，用 `rhine_09` 的"倒计时小卡"：一枚深色小卡 + 琥珀图标 + 等宽数字，贴在角落——**比闪红框高级，也更像"仪器在报数"**。

### I.4 星图 → 技术图纸 / 蓝图

- **白纸 + 8px 网格（1px @4% 黑）+ 细构造线 + 引线标注 + 定位标记（四角小十字）** 就是"星图"在莱茵语言里的形态。
- agent 节点用"chip 形状"（34×34 方块 + 单字母）+ 引线连到名称与指标；连线 1px，交叉处可加小圆点；整个图不带发光、不带渐变。
- "星座连线"用**图纸引线**（直线 + 小折角）而不是曲线光带——这是莱茵生命与星铁最大的风格差异点。

### I.5 开机序列 → 蓝图逐层显影

- 四拍（约 1.2–1.4s）：① 8px 网格淡入 200ms；② 四角定位标记 + 外框细线描边绘制 500ms；③ 内部结构/数据块以 60ms 间隔逐个淡入 300ms；④ 标题与页码 200ms。
- 结束后进入"待命"：**只有一条 1px 的扫描线每 8s 自上而下扫过一次**（不透明度 8%），以及等宽数字光标闪烁。
- **与星铁/ZZZ 的区分**：这套开机完全不"神圣"也不"炫"，它传达的是"仪器自检完成，可以开始记录"——正好适合作为 ASTRA 的**默认/日常模式**，把星铁式的书页留给"历史回看"，把 ZZZ 式的虹膜环留给"AI 连接/异常"。

### I.6 角色/agent 图例 → 职能 chip

- 5–6 种状态用 chip 表达（H-3）：本机（∞ 或功能符号）/ 运行中（橙）/ 健康（青）/ 待处理（灰）/ 告警（红）/ 归档（浅灰描边）。
- 图例放在面板左下角，一字排开，下方 11px 标签——**这是全站唯一的"图例区"，其余地方不再重复解释颜色**。
