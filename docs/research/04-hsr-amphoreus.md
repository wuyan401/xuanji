> **目的**：为「ASTRA 观测台」——本机所有 DeepSeek Harness agent 会话的实时数据可视化——提取**可迁移的视觉机制**。只借机制，不复制皮肤；最终产品必须自绘，不嵌入任何官方素材。

## 0 结论摘要（先读这段）

1. **翁法罗斯的主色不是金色，是冷蓝大理石。** 13 张场景 CG 里 11 张的主色落在 205°–220° 的冷蓝色相带，Okhema 圣城单图 `#508ad4` 占 14.7%、`#a5c6f4` 占 9.5%、`#cde6f5` 占 7.5%，整体 `meanLum 158 / meanSat 54%`【实测】。鎏金在场景里是**极小的点缀**，不是主色。
2. **"神圣感"来自高亮度 + 高饱和冷蓝 + 大面积低对比石材质感的组合**，而不是来自细节密度。Okhema 白天版画面亮度均值 158/255，比黄昏版（72.8）高一倍以上；同一个地点换光照就能把"圣洁"翻成"末日"，说明这套美术的情绪开关是**光照色温与亮度**，不是造型。
3. **暖色是配给制（rationed accent）。** 13 张场景里暖色（色相 < 60° 或 > 330°）占比超过 7% 的只有 3 张：黄昏 Okhema（`#bc7c71` 7.4%）、Nightmare's Echo（红发光条 + 紫核）、Temple of Ages（余烬橙）。其余 10 张画面里暖色总面积 < 5%【实测】。→ 我们做告警色时应当沿用这个预算纪律。
4. **"如我所书"的视觉本质是"记忆画册"，不是"书本 UI"。** 三张界面图分别是：一张**撕边单页记忆画**（`hsr_15`，古铜褐 `#2f2719` 10.2% + 米白 `#c3baab` 10.0%，`meanSat 22.6%`）、一张**长幅跨页插画**（`hsr_16`，几乎全灰 `meanSat 12.4%`，只有紫色花丛一处高饱和）、一张**整页装饰卡**（`hsr_17`，`#f4f2ea` 13.7% + `#cbb8a3` 13.4%，底部是伪符文章节横幅）【实测+目视】。→ 可迁移的是"画册式档案"这套**版式语法**，不是某张画。
5. **官方设定长图（`hsr_18`/`19`/`20`）是本参考系里信息设计含量最高的样本**：一张图里同时有 Didone 大标题、三层同心环状数据图、菱形徽记卡、胶囊标签、尺规刻度线、撕纸分页、网格注释卡。`hsr_18` 的"提坦轮盘"直径约 600px，占 900px 画幅的 **67%**，12 扇区每 30°，是本项目**星图**布局最直接的机制来源【实测】。
6. **配色结构是三段式**：外景=冷蓝高亮（`#508ad4` 系）；内景=低饱和暖褐/青灰（`#445765`、`#464e4b`，`meanSat 18–22%`）；书页=暖白纸 + 墨褐字 + 一点蓝紫（`#f4f2ea` / `#2f2719` / `#6a6f86`）。三段各自承担不同职能：空间、情境、文本。
7. **可迁移度最高的 3 个机制**：① 12 扇区同心环数据轮盘（层级=环宽，状态=缺席）；② 撕纸分页 + 纸面叠层（章节切换）；③ 单色记忆画 + 一处选择性色彩（事件账本里的"历史快照"）。
8. **必须避开的皮**：提坦们的专名与 sigil 图形、伪符文（Titan script）字形、"Titan / The Pantheon of Titans"这类字标、HoYoLAB 长图的具体版式（直接照搬会变成仿官方公告）、以及整套"大理石+鎏金"的希腊化造型语言。

## B 逐图观察

> 观察维度固定为六项：构图 / 镜头 / 光照 / 材质 / 元素 / 信息层级。每张 2–4 行，只写能支撑结论的观察。

### B.1 场景组（13 张）

**01 · Okhema 圣城（白天）** — 构图：中央大道纵深 + 两侧对称巨构，上方一个**巨大的环形结构**横跨天际（"神圣环"）。镜头：人眼高度，广角，中央一点透视。光照：正午高空光 + 大面积蓝天漫反射；阴影极浅。材质：白色大理石（高反射、低纹理）、浅蓝天光、雾气弱化纵深。元素：雕像、柱列、飘浮的环、鸟群。信息层级：单焦点（环）→ 中景建筑 → 近景铺地；画面留出 > 30% 的天空作为"呼吸区"【目视】。**这张是全组唯一"无压迫感"的图，是"明亮仪表盘"的参照。**

**02 · Okhema 黄昏（Fallen Twilight）** — 构图：同机位，环结构变成**破裂悬浮的巨环**，城市下沉。光照：暖橙逆光 + 深蓝环境光，温差极大（`#bc7c71` 7.4% vs `#1d2c4f` 13.9%）【实测】。材质：石面从冷白变成暖灰，出现烟尘与火花。元素：坍塌、飞行器、废墟轮廓。层级：高对比、焦点被逆光压成剪影。**同场景换光照即换情绪——这套美术的情绪开关是色温/亮度，不是造型。**

**03 · Janusopolis 圣所** — 构图：三开间纵深柱廊，中央尽端是发光拱门。镜头：中低机位，略仰。光照：极低饱和青灰（`meanSat 18.3%`），光源在画面深处。材质：大理石 + 铜饰 + 水面反射。元素：巨型门、悬挂徽记、无声的对称。层级：纵深主导，明度递进（近暗远亮）。**低饱和 + 强纵深 = "肃穆"。**

**04 · Great Tomb「万有矩阵」** — 构图：正中一个青蓝色光柱/传送门，地面同心圆台座。光照：暗场 + 单一冷光源 + 垂直光柱。材质：黑石、蓝晶、雾气。层级：中心最亮，四周压暗（`meanLum 95.8`）。**"仪式场"的原型：一个中心光、一个圆台、四面对称。**

**05 · Great Tomb「梦魇回声」** — 构图：仰视一个坍塌的巨型竖井，碎石悬浮，正中一个**紫金光环**（细金边 + 紫核心 + 内部碎裂符号），环下方一个小蓝菱形徽记。光照：紫蓝雾 + 核心自发光 + 石壁上**胭脂红发光条（细长、约 4–6px @1080p）**。材质：湿石、金边、能量丝。层级：光环 > 红色警示条 > 碎石。**这是全组最强的"告警光"样本：低明度底色 + 极窄的高饱和红发光条。**

**06 · Dawncloud 议事厅** — 构图：内景长廊，侧窗投光，右侧有旗与阶梯。光照：自然侧光 + 极低饱和（`meanSat 19.7%`）。材质：浅石、木、织物。层级：以灰绿/灰褐为主，唯一暖色是 `#6e382d`（织物，6.5%）与 accent 候选金 `#f5c94b`。**群像/议事场景用"低对比 + 一点织物暖色"来降低戏剧性。**

**07 · Dawncloud 无光礼拜堂** — 构图：内景，人群剪影，远处红光。光照：暗紫红（`#4d4863` 15.3%、`#2f2627` 13.5%），唯一亮点是 accent `#fb4317`。材质：紫灰石、烛火。**"集体仪式"要靠极暗 + 极窄暖色点。**

**08 · Castrum Kremnos 战场** — 构图：蓝灰石城 + 鎏金雕像，仰视。光照：明调冷蓝（`meanLum 139.5`）+ 土黄石材。材质：粗石与金属。层级：白蓝灰过渡 + 一点土黄（`#6e624e` 10.1%）。**"纪念性建筑"的配方：明调冷蓝 + 土黄石材 + 金色雕像。**

**09 · 大理石宫（Marmoreal Palace）** — 构图：白蓝石宫 + 青绿水流，右侧一棵树。光照：天光 + 水反射。材质：白石、青绿水面（`#287352` 9.0%）、水雾（`#aad5de` 7.5%）。**"生机"用青绿介入冷蓝。**

**10 · 万古神殿（Temple of Ages）** — 构图：仰视，中央拱门 + 星形门徽，两侧柱列。光照：深海军蓝（`meanLum 63.4`）+ 地面余烬橙（数十个 2–4px 亮点）+ 左前景一团铂金色火焰。材质：深石、金箍、飘浮金饰、紫色草。**"冷场里的暖微粒"——最优雅的告警/活跃态语法：底色冷，活动用密集的极小暖光点表达，整体亮度仍低。**

**11 · 天穹壁画（Celestial Mural）** — 构图：室内大壁画前，中景有展台。光照：青灰（`#475c67`、`#77a3b4`），accent 橙 `#ff6500`（极小）。**"文物/档案室"：低饱和青灰 + 展台打光。**

**12 · 预言档案馆（Archive of Prophecies）** — 构图：深蓝阶梯大厅，顶部虚空。光照：极暗（`meanLum 46.9`），只有点缀高光。材质：深蓝石、微光柱子。**"知识空间"=极暗 + 稀疏亮点 + 强纵深。**

**13 · 星穹之穹（Dome of the Stars）** — 构图：正中一个星云球体，周围环形展台。光照：蓝紫高饱和（`meanSat 55.5%`），主色 `#3462b9` 16.7% + 品红紫 `#bb79b5` 13.6%。**"星图"原型：冷蓝底 + 品红点缀 + 中心球体 + 环形围绕。**

### B.2 「如我所书」界面组（3 张 + 1 张章节卡）

**15 · 单页记忆画（Chapter 1 Act 2 Scene 1）** — 一张 712×348 的**横向插图页**：画面是低饱和古铜褐（`#2f2719` 10.2%）与米白（`#c3baab` 10.0%）构成的"旧画"。构图：斜向分层，左下有倒地人物、上方有白衣人物、右侧有三人群像。四边是**不规则撕纸/毛边**（白边 6–14px 不等），画面外缘有一圈柔和暗角。左上角有小块正文文字（中文字，字号约 9–10px @712 宽，两行）。**关键：这是"叙事内容"，不是"导航控件"——它靠"旧画 + 撕边 + 小字"传达"这是被记录下来的过去"。**

## C 实测调色板

### C.1 测量方法

- 工具：`astra/tools/palette.py`（PIL + median-cut，量化到 12 色），命令：`python tools\palette.py docs\research\assets\amphoreus --json docs\research\assets\amphoreus\palette.json`。
- 每色输出：`hex` / `rgb` / `share`（占画面像素百分比）/ `lum`（HSL 亮度 0–1）/ `sat`（HSL 饱和度 0–1）/ `hue`（色相度数）。
- 每图汇总：`meanLum`（0–255 的平均亮度，**不是** HSL 的 0–1）/ `meanSat`（0–255 尺度下换算的百分比）/ `accentCandidate`（脚本给出的强调色候选，取"高饱和且非主色"的色）。

| **氛围光** | 冷蓝辉光 `#34ade7`/`#29a3f7`/`#3c8af7`；紫辉 `#b293e7` | 1–6%，多为发光体边缘 | 用发光而非填色表达"能量/魔法/神性"；永远伴随大面积暗底 |

**配色用途逻辑（为什么是这套）**：
- **蓝=世界，金=神性**：环境（大理石、天空、深井）全部压在冷蓝带；金只出现在徽记、雕像、书页装饰边、标签胶囊。等价到产品：**蓝=容器/环境，金=数据中的"重要且正确"**。
- **褐色=被记录的时间**：`hsr_15/16/17` 三张书页把色相整体拉向 30°–45°（羊皮褐），饱和度压到 12–27%，亮度则分三档（94 / 130 / 179）。→ **同一套"手稿"主题可以有三种明度档，用来区分"久远记忆 / 记忆 / 新写的一页"**。
- **黑白二值=概念的最小单元**：章节卡 `meanSat 0.0%`，只靠轮廓识别。→ **给"节点/章节"设计徽记时，先保证黑白也能识别**。

## D 字体与排版

### D.1 可确证的事实（从图直接量到）

1. **英文大标题是 Didone（现代衬线）**：`Titan`（`hsr_18`）与 `The Pantheon of Titans`（`hsr_19`）、`Three Titans of Fate`（`hsr_20`）都具备"极高粗细对比 + 发丝衬线 + 垂直字轴 + 无托架"特征【目视】。`Titan` 单字高约 62px @900px 宽画幅。
2. **正文是低对比衬线（old-style / transitional）**：字重常规、有轻微笔锋、x-height 中等；`hsr_18` 副标 14–16px、行高约为字号的 1.5–1.6 倍【目视估算】。
3. **层级靠"字号跳跃 + 颜色明度"而非颜色本身实现**：`Titan`（62px）→ 副标（15px）→ 环内领域名（13px）→ 环外 realm 名（11px，`letter-spacing` 明显加宽，约 +0.08em 视觉）【目视】。整张图只有 2 个文字颜色：藏青（`#313e60`）与灰蓝（`#5f6f91` 附近）。
4. **存在一套自造的伪文字（Titan script）**：`hsr_17` 底部横幅、`hsr_18` 顶部条带、`hsr_19` 右上角都出现"方块化、等宽、无大小写、笔画角度多为 0/45/90°"的字形串。它的功能是**纹理与"异世界感"**，不是可读内容【目视】。
5. **CJK 正文很短**：书页里出现的中文只有 2 行小字（约 9–10px @712 宽）；游戏内 CJK UI 无法从这批素材确证字体（截图里多为英文）。
6. **书页装饰字**：`hsr_17` 的页边纹样与顶部徽章是**图形化的线描**，不是字；但它们和伪符文使用同一套笔宽（约 2px @488 宽）。

### D.2 推测（需二次验证）

| 项目 | 推测 | 依据 | 风险 |
|---|---|---|---|
| Didone 标题字体 | Playfair Display / DM Serif Display / Cormorant 一类高对比衬线 | 发丝衬线 + 高对比 + 直立轴 | 字重与细节不同；建议自选一个开源 Didone 并调字距，别硬仿 |

## E UI 信息架构解剖

### E.1 「提坦轮盘」= 一张可复用的"环形数据图"规格书

这是本次调研里**信息密度与可读性平衡最好**的一个图元，值得逐项记录（均从 `hsr_18` 900×1200 实测/估算）：

| 属性 | 值 | 含义 |
|---|---|---|
| 整体形状 | 正圆，直径 ≈ **600px = 画幅宽 67%** | 环形图应占内容区 2/3，留 1/3 给标题与说明 |
| 分扇区数 | **12**，每扇区 30° | 数量上限：再多则标签放不下；再少则显得空 |
| 扇区分隔 | 1px 藏青线（`#313e60`，≈100% 不透明） | 靠**发丝线+留白**分区，不用色块厚度 |
| 环层数 | **4 层**：realm 外环（52px）→ 名称环（95px）→ 领域环（55px）→ 中心区（半径 120px） | 层级 = 环宽 + 字号，双重编码 |
| 文字方向 | 名称环为**切向排布**（沿圆周旋转），realm 与领域环为**径向水平** | 切向排布让 12 个名字都能读；径向排布适合短词 |
| 各扇区图形 | 40×40px 单色线稿 sigil，约 2px 等粗线 | 图形承担"快速识别"，文字承担"精确识别" |
| 中心 | `∞` 符号 + 极浅底纹 | 中心不是数据，是"世界观符号"；给 hub 留一个语义位 |
| 未解锁态 | **只剩环线与空位，文字整块消失**（不是灰字） | 状态语言：缺席 ≠ 淡化 |

### E.2 书页/章节结构（`hsr_17` / `hsr_15` / `hsr_16`）

- **层 1：整页框架**——纸底 + 对称装饰边框（藤蔓/结绳）+ 四角装饰 + 顶部徽章 + 底部横幅。这是"章节页"。
- **层 2：内容槽**——中央图形/插画（`hsr_17` 是人物图形，`hsr_15/16` 是整幅记忆画）。
- **层 3：文字槽**——极小的正文（9–10px）+ 底部横幅内的伪符文（装饰）。**文字被故意压到最小**，让"图像=叙事"、"文字=注脚"。
- **切换语义**：单页（1 张画）↔ 跨页（Spread，横向拉宽）↔ 整页装饰卡（角色/条目页）。三种版式对应三种"记录粒度"。
- **撕纸边不是随机噪声**：`hsr_15/16` 的白边宽度在 6–14px 之间变化、且有方向性（下缘更宽），像"从书上撕下来的一页"贴在深色底上。→ **实现时用 clip-path 多边形（8–16 段）而不是 SVG 滤镜，性能与可控性更好。**

### E.3 边框 / 切角 / 装饰语法（全部取自官方长图）

1. **纸面叠层**：深色底 → 撕纸白/米纸 → 内容。至少 2 层，最多 3 层（`hsr_20` 有 3 层：藏青底 / 米白区 / 注释卡）。
2. **发丝线系统**：1px 细线 + 双线 + "末端 `+++`" 三种变体；尺规感来自**细线上的等距短刻度**（`hsr_19` 标题下的双线，刻度间距约 12px）。
3. **胶囊标签**（pill）：圆角 100%（全圆）、高 26px、内嵌图标或符号、两端带对称装饰（`✳`）、外描边 1px 或暗 1 级底色。`hsr_19` 顶部 `✳ ◇Z ✳` 与 `hsr_20` 的 `⟡ Time Titan ⟡` 是同一族。
4. **菱形徽记卡**：正方形旋转 45°，双层描边（外奶油 8px + 内深色 1px），中心放 sigil。`hsr_20` 三条并列，形成"卡片列"。
5. **注释卡**：圆角矩形 + 比底色亮 5–8% 的填充 + **细点阵纹理**（点距约 8px，不透明度 < 6%）+ 圆头像 + 胶囊标题 + 正文。
6. **装饰带**：`hsr_20` 底部的圆形点阵波段（一排圆点，直径约 4px，间距 12px）——纯装饰，用来分隔"页脚"。

### E.4 图标（sigil）语言

从 12 个 sigil 归纳出的构造规律（这条对我们"agent 徽记自动生成"极有用）：
- **单色、等粗、纯线稿**：约 2px 描边 @900px 画幅；无填充、无渐变、无阴影。
- **构图居中、外接方框 40×40px、留白 ≥ 4px**。
- **对称或准对称**：大多数是"左右镜像"或"旋转对称"。
- **由 2–3 个几何原语组合**：菱形/三角、圆/半圆、平行竖线、波浪线。
- **不用具象物体**（不画人、不画动物）：全部是抽象符号。
- → 我们的 agent sigil 生成器可以直接采用这套约束：**等粗 2px、40×40、2~3 个原语、镜像对称、单色**。

### E.5 状态语言

| 状态 | 表达方式 | 出处 |
|---|---|---|
| 已记录 / 已解锁 | 有文字 + 有 sigil + 环带完整 | `hsr_18` 全部扇区 |
| 未记录 / 未解锁 | **文字整块缺席**，只剩环线与空位 | `hsr_18`（图上部/下部有空扇区） |
| 神圣 / 正确 | 金色（`#f5c94b`、`#ffb40b`）微面积点亮 | `hsr_06` accent、`hsr_17` 强调金 |
| 危险 / 灾厄 | 猩红（`#fd2b5b`、`#ef3026`）极窄条或极小面积 | `hsr_05` 红色发光条、`hsr_02` |
| 记忆 / 历史 | 低饱和褐色 + 单一选择性色 | `hsr_15/16` |
| 概念 / 章节 | 黑白二值徽记 | `hsr_14` |

## F 动效与转场语言

> ⚠ 本节**没有录屏证据**，全部由静态图的工艺推断 + 游戏 UI 常识给出；标注为 `【推测】`，实现前应实机确认（可通过官方 PV 或实机录屏验证，但录屏属另行取证，未纳入本次资产）。

1. **翻页 / 换章**`【推测】`：书页 UI 的动画主体是"纸的物理感"——页角先翘起，再整页沿装订线转 3D（约 12–18° 的透视压缩），落页时有一帧轻微回弹。建议节奏 **450–600ms，ease-out-quint**；跨页切换时先暗 80ms 再亮。
2. **撕纸揭示**`【推测】`：`hsr_15/16` 的毛边意味着"这一页被从别处撕下来"，对应动画应是**边缘不规则的遮罩从一侧推入**（而不是淡入）。建议用 clip-path 关键帧 6–8 段，**700–900ms**，前 60% 快速推进、后 40% 减速贴平。
3. **书写 / 记录**`【推测】`：官方标题下的细线与 `+++` 装饰像是"刚画上去的标尺线"；"如我所书"的语义就是"正在被写下的书"。建议记录类动画采用**从左到右的描边绘制（stroke-dashoffset）**，速度 **1200–1800ms/屏**，配合一次微弱的光晕扫过（1 次，不循环）。
4. **选择性色彩点亮**`【推测】`：`hsr_16` 的"全灰 + 一处紫"强烈暗示动画是"颜色从上到下覆盖"或"局部点亮"。建议 **先灰后彩，600–900ms，只对 1 个语义对象上色**，其余保持灰。
5. **环状数据更新**`【推测】`：轮盘这类图形在游戏中通常按"顺时针扫描 + 数字滚动"刷新。建议 **扫描线 1 圈 900ms（ease-in-out）**，扫过的扇区文字延迟 40ms 逐个亮起；数字用 **等宽字体 + 滚动 300ms**。
6. **光晕 / 氛围**`【推测】`：场景图的光晕都很克制（只在发光体边缘 1–6% 面积）。建议 **辉光只用 1 层、半径 ≤ 24px、强度 ≤ 0.35**，禁止多层堆叠（会变廉价）。
7. **禁止项**：不要给这套古典纸感配"故障/glitch"效果（语义冲突：古典=手工，故障=数字破损）。

## H 3 条可直接落地的设计规则

> 以下三条都来自本报告前面的测量，可直接写进 design token 或组件规范。

### H-1 星盘（星座图）按"4 环 × 12 扇区"建，环宽比 52 : 95 : 55 : 120

- **依据**：`hsr_18` 轮盘直径 600px / 画幅 900px = **67%**；四层环宽实测约 52、95、55、中心半径 120px（比例 0.52 : 0.95 : 0.55 : 1.20）【实测/估算】；扇区数 12，每 30°，分隔线 1px。
- **落法**：面板宽度 `W` 时，轮盘外径 `0.67W`；环宽 = 外径 × (0.087 / 0.158 / 0.092)；中心区半径 = 外径 × 0.20。扇区分隔线 `1px rgba(255,255,255,0.18)`（暗底）或 `1px rgba(0,0,0,0.12)`（亮底）。
- **禁忌**：扇区数不要 > 12（文字放不下），不要用色块填充扇区（原图靠发丝线 + 留白分区）。

### H-2 纸张三档明度 + 单一强调色，强调色面积 ≤ 8%

- **依据**：三张书页的 `meanLum` 分别为 94.3 / 129.7 / 179.3，`meanSat` 22.6% / 12.4% / 27.1%；场景组里暖色（`hue<60°` 或 `>330°`）超过 7% 的只有 3/13 张，其余 < 5%；`hsr_17` 的强调金 `#ffb40b` 目视面积 < 1%【实测+目视】。
- **落法**：三档纸色建议 `#2f2719`（旧）→ `#c3baab`（中）→ `#f4f2ea`（新）；强调色全站只用 1 个（推荐金 `#f5c94b` 或 `#ffb40b`），**任何一个视口内强调色像素占比 ≤ 8%**，且只允许出现在"重要且正确/神圣"的语义上。
- **验收**：截图后跑一遍 `palette.py`，若主色前 3 里出现强调色，说明超预算。

### H-3 记忆画/账本条目：全图去饱和到 ≤ 15%，只保留 1 个高饱和对象

- **依据**：`hsr_16` 跨页图 `meanSat 12.4%`，全图唯一饱和是紫色花丛（accent `#8e5cad`）；`hsr_15` `meanSat 22.6%` 但仍以褐灰为主。语义：**"记忆整体褪色，只有这件事还鲜活"**。
- **落法**：历史事件卡片的缩略图/插画层加 `filter: saturate(0.12)`；给"当前关注的那个对象"单独一层不加滤镜（或用 `mix-blend-mode`/mask 恢复颜色）。文字层保持 `#2f2719`（旧页）或 `#f4f2ea`（亮页）不变。
- **禁忌**：不要对整图做"羊皮纸纹理 + 暗角 + 噪点"三件套滤镜（会像廉价的复古 App），原图的旧感来自**纸边 + 低饱和 + 低对比**，不是噪点。

## I 与 ASTRA 产品的关联

ASTRA 需要展示：**本机所有 agent 会话的实时状态**（星图 / 仪表盘 / 事件账本 / 告警 / 开机序列）。逐项映射如下。

### I.1 星图 / 星座 → 提坦轮盘（最强映射）

- **结构**：轮盘 1 圈 = 本机；12 扇区 = 12 个 agent 槽位（或按"分组"切扇区，扇区内再分 3 个小弧）。四层环分别承载：外环 `provider/model`，第二环 `agent 名`，第三环 `当前任务类型`，中心 = 全局 hub 状态。
- **节点**：每个 agent 一个 **sigil**（按 E.4 的约束程序生成：等粗 2px、40×40、2–3 原语、镜像对称、单色）——**保证每个 agent 的图标看起来是"同一套系统里的符号"，而不是 12 个 emoji**。
- **"未激活"用缺席**：没有会话的 agent 不在环上画灰点，而是**整块扇区只有环线**（直接借 E.5）。这比灰点更清晰——灰点会被误读为"离线但存在"，缺席读作"此刻不存在"。
- **星座意象的正确用法**：不是画真正的星座图，而是**把"会话之间的调用关系"画成环外的细弧线**（跨扇区的贝塞尔弧），线宽随调用频次 1→2.5px。星穹之穹 `#3462b9 + #bb79b5` 的"冷蓝+品红"可以只用于**跨 agent 的连线**（品红只给高频），呼应 `hsr_13` 的配色配给。

### I.2 仪表盘 → 冷蓝结构 + 米白数字 + Didone 大数

- 底色用**暗场藏青**（`#1d2c4f` / `#313e60`，来自 `hsr_02/19`），数据值用**米白**（`#e5e7ea`），单位与说明用灰蓝（`#5f6f91`）。
- 大数字用 Didone（字号跳跃 3.4×，如 54px 标题 / 16px 说明），小数用等宽（避免跳动）。
- 结构线全部用 1px 发丝线（`rgba(233,235,238,0.10)`），禁用粗边框与卡片阴影——**翁法罗斯没有任何"卡片投影"，空间感来自线、光、纸三层**。

### I.3 事件账本 → 如我所书（三段式记录）

- **章节 = 会话**：一个会话 = 一个"章节页"，用黑白徽记做章节标识（`hsr_14` 的做法：先保证黑白可识别）。
- **条目 = 一页记录**：每条事件是一张"撕边纸片"，纸的明度编码时间远近（新事件用 `#f4f2ea`，越旧越往 `#c3baab` 走，超过 24h 用 `#2f2719` 底 + 米白字）。
- **焦点 = 选择性色彩**：当前选中的那条事件，其缩略图恢复饱和（H-3），其余去饱和。
- **翻页 = 切章**：切会话时用翻页转场（F.1 节奏），不要用现成的 slide/fade。
- **文字层级**：条目标题用 18–20px 衬线，正文 13–14px/1.6，元数据（时间、token 数、耗时）压到 10–11px 且用**灰蓝**而不是灰——保持色相统一。

### I.4 告警 → 配给制暖色 + 极窄发光条

- 三个等级直接映射已实测的三种暖色：**提示=金 `#f5c94b`（≤2% 面积）→ 警告=焰橙 `#ff8025`（≤4%）→ 危险=猩红 `#fd2b5b`（≤6%）**；底色始终是暗场（`#1d2c4f`），**永远不要整屏变红**。
- "低明度底 + 极窄高饱和发光条"（from `hsr_05` 的红色凹槽）比"闪烁红框"高级得多：条宽 2–4px、发光半径 ≤ 8px、只在状态变化时亮 1 次（不循环闪烁）。
- 若需要"持续活跃"的暗示，用 `hsr_10` 的做法：**一簇极小暖光点**（2–4px、散布在容器底部），而不是脉冲边框。

### I.5 开机序列 → 撕纸揭示 + 书写描边

- 序列建议 3 拍：① **纸面生成**（0–700ms）：从中心撕纸遮罩向外扩展；② **结构线绘制**（700–1500ms）：尺规细线 + 刻度按 stroke-dashoffset 画出，环盘同时顺时针扫描；③ **首次记录书写**（1500–2500ms）：标题与第一行事件文字按"书写"从左到右出现，结尾一次 300ms 光晕扫过（仅 1 次）。
- 全程不用 loading 转圈；不用故障效果；不用弹跳（ease-out 系列）。
- 开机后进入"待命"状态时，画面允许保留 1 处微弱的金光呼吸（周期 4–6s，强度 ≤ 0.2），作为"系统活着"的最低成本信号。

## 附录 C：本参考系不可替代的三个点（给 Lead 的综合提示）

1. **它是三家里唯一能承载"叙事/命运/记录"这套语汇的参考系。** ZZZ 提供的是终端手感，莱茵提供的是档案纪律，只有翁法罗斯提供了「**事件被书写成历史**」的视觉隐喻（书页、章节、记忆插画、伪符文、轮盘上的缺席格）。ASTRA 的"事件账本 / 会话复盘"应当主要借这一支。
2. **它是三家里唯一有"星图原生形态"的参考系。** Titan 轮盘就是一张 12 扇区、4 层环的数据星盘，且已经证明"如何在一个圆里放三种不同抽象层级的信息而不乱"。ASTRA 的星图页优先借轮盘的**分层逻辑**（不是它的 glyph 与专名）。
3. **它是三家里唯一允许"高饱和冷色 + 高亮度"同时出现的参考系。** Okhema 白天 `meanLum 158.1 / meanSat 54.2%`——高亮且高饱和仍然不显廉价，靠的是"低对比石材 + 明确光源 + 冷蓝为骨"。若 ASTRA 需要一版"明亮、宏大、庆典式"的默认主题，只有这一支给出了可用证据。

**与另两支的硬冲突（不可混用）**：
- 翁法罗斯的"暖白纸 + 墨褐 + 单一强调色"与莱茵生命的"纸白 + 冷白荧光 + 单橙"**长得很像**，但气质相反：前者是"手抄本"，后者是"实验记录"。同时使用会让 ASTRA 变成"两种纸"。
- 翁法罗斯的"神圣尺度"（巨构、仰视、过曝天光）与 ZZZ 的"贴纸/涂鸦/网点"是**同一空间里不能共存**的两种真实性。建议按"页面模式"隔离，而不是在同一屏混搭。
