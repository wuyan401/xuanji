## 0. 方法与工具链(可复现)

- 采集:`Invoke-WebRequest` 抓 Steam Web API 的官方截图与官方开发日志图;Paradox 官网页面用 `web_fetch`;Fandom/wiki 页面用只读 API。
- 测量:`python tools/palette.py <图…> --json palette.json`(中位切分量化,输出每图 12 色 + 占比 + lum/sat/hue + 全图 meanLum/meanSat + accentCandidate)。
- 拼版:`python tools/contact_sheet.py <目录> --out _contact_sheet.jpg --cols 4`(便于整组比对)。
- 观察:逐张用 `read_image` 打开原始 1:1 像素的入选图(非仅缩略图),记录构图/光照/信息层级;并对关键面板做像素级取色与线宽扫描(Pillow `getdata`/逐行扫描,脚本一次性使用,数据已写入本报告)。
- 重要口径:**本报告所有 hex、占比、亮度、对比度、线宽均为实测值**;凡未实测的 px 尺寸或动效时值,均标注「目测」或「推测」。

## B. 逐图观察(16 张入选图;构图 / 镜头 / 光照 / 材质 / 元素 / 信息层级)

编号与文件一一对应,文件均位于 `docs/research/assets/stellaris/`。像素统计取自上表 `palette.json`。

### B1 `stellaris_01_galaxy_map_hyperlanes_outliner.jpg`(1920×1080,meanLum 24.4 / meanSat 9.3)
- **构图:** 全屏银河图,信息主体在中央偏右;右缘 298px 宽 outliner 面板(实测裁切 1620–1918px),左缘约 40px 图标竖栏,顶部资源条,底部中央一个「Close Galaxy Map」胶囊。
- **镜头:** 正交俯视的星系图,等效「地图模式」;无透视,靠线宽与节点大小表达远近(不是 3D 景深)。
- **光照:** 几乎无光照叙事。**纯黑占 52.27%**(全图第一色 #000000),星点为白点,hyperlane 为浅蓝细折线;氛围光只存在于星云与恒星图标。
- **材质:** 扁平矢量为主,叠一层极轻的星尘纹理;节点为圆形徽记(每种恒星类型一个符号),选中节点有细圆环。
- **元素:** 势力领土=半透明多边形色块(橄榄棕/暗红/青/紫蓝,低饱和);hyperlane 折线;星名小字;outliner 分组(Sectors / Empire Capital / Shipyards / Military Fleets / Civilian Ships…),每组可折叠,行内含图标+名称+数值。
- **信息层级:** ①地图中央(视线第一落点)→ ②右侧列表(可操作对象)→ ③顶部资源(全局状态)→ ④底部模式按钮。**信息密度极高但底色几乎全黑,所以不显得吵**——这是最值得研究的一条。
- **实测颜色:** #000000 52.27%、#555863 7.62%(星点/文字灰)、#454049 5.88%(领土暗紫)、#232f2f 4.73%(领土青)、#78898a 4.42%(高亮线);accent #da1519(敌对红)。
- **可迁移点:** 「低饱和线网 + 大面积近黑 + 少量高饱和标记」的星图语法;outliner 右侧分组列表;顶部资源条。

### B2 `stellaris_02_colony_management_over_galaxy.jpg`(1920×1080,meanLum 36.6 / meanSat 13.2)
- **构图:** 银河图之上浮起一扇 2 栏管理窗(左:行星概览/区划/建筑/建造队列;右:Building Details),窗口约占屏 45%,不遮全屏。
- **镜头:** 同上正交地图;窗口是「贴片式」叠在世界上,而非全屏页面。
- **光照:** 窗口底色是**深灰绿**而非纯黑(实测 #303736 占 11.44%、#18191a 11.44%、#0d0f10 11.82%),比背后的银河亮 2–3 倍,形成"浮起"的层次;文字为浅灰白,少量橙金强调 #f9940a。
- **材质:** 面板像磨砂金属/深色玻璃,分区靠 1px 内阴影勾边;没有玻璃拟态的模糊,是实心半透明。
- **元素:** 页签栏、Governor 头像、Districts 图标网格(2 行)、Buildings 4×3 图标网格、Build Queue 列表(行内图标+名称+状态)、底部标签(Planet Summary / Population / Armies / Corporate)。
- **信息层级:** 区域顺序=「身份(星球名/类型)→ 状态(区划缺口)→ 建造(可执行项)→ 结果(队列)」;图标承担 90% 识别,文字只做确认。
- **实测颜色:** 面板 #303736/#282929/#1f2424;底色 #0d0f10;强调 #f9940a(资源/警示金色)。
- **可迁移点:** 「世界之上浮窗」而非整页切换;页签+网格+队列的三段式;深灰绿面板比纯黑更有材质感。

### B3 `stellaris_03_star_system_event_popup.jpg`(1728×1080,meanLum 23.7 / meanSat 41.4)
- **构图:** 星系视图(行星沿细椭圆轨道排布),左侧偏中弹出事件窗(约占宽 1/3);顶部资源条完整可见,底部中央是系统铭牌+「Paused」。
- **镜头:** 正交俯视;事件窗是唯一「前景层」,世界被压暗但未移除。
- **光照:** 深蓝恒星系为底(实测 #04070e 10.79%、#091016 11.36%、#0f161c 7.89%),事件窗内部更暗(#000003 8.12%);宇宙底色的蓝黑是「低明度+中饱和」组合。
- **材质:** 事件窗=深色平板+顶部一张黑体插画(黑洞图),正文小字多行,选项行是浅薄荷绿文字;窗缘无花边,只有 1px 亮暗分隔。
- **元素:** 顶部资源 chips(每种资源=图标+数字+增量)、事件标题条《The Unbounded》、正文、选项列表、系统铭牌、「Paused」橙字。
- **信息层级:** 事件窗 > 顶部资源 > 星系本体。**事件窗压在世界之上,但世界仍可见**——不打断空间感。
- **实测颜色:** 底色 #04070e/#091016;事件窗 #000004/#080b10;正文白 #f9ffff;选项文字浅薄荷绿 #e2faed;accent #d16211。
- **可迁移点:** 「浮层事件窗 + 保留世界背景」;选项用浅绿文字而非按钮底色。

### B4 `stellaris_04_species_creation_ui.jpg`(1728×1080,meanLum 56.9 / meanSat 13.8)
- **构图:** 全屏创建器:左 200px 竖向导航(分 4 组、12 个条目),中央面板(种族外观+肖像网格),右缘竖向肖像缩略条带勾选态;背景是行星地平线(暖棕金)。
- **镜头:** 相机看向行星,背景为低景深大色块;UI 面板半透明压在背景上。
- **光照:** 背景暖金棕(实测 #736e5d 9.27%、#4f4e43 9.32%、#423832 6.86%),UI 面板是**暗青绿玻璃**(实测左栏填充 #172621、边框 #2a2e2f),冷色 UI 与暖色美术形成互补对比。
- **材质:** 面板近实心(能透出很少背景),边缘切角+细亮线;选中项用亮边框+文字加亮。
- **元素:** 左侧分区标题(Species / Homeworld / Origin / Empire)与子项;中央 Appearance 面板;物种分类列表(Humanoid/Machine/Mammalian/Reptilian/Avian/Arthropoid/Molluscoid/Fungoid/Plantoid);肖像 9×2 网格;右缘已选肖像列。
- **信息层级:** 左=流程导航,中=当前步骤,右=已选结果;文字小、图标密、留白极少,靠分组标题与分隔线维持可扫读。
- **实测颜色:** 背景暖 #736e5d;面板 #172621;强调红徽 #d05e3d;正文浅灰白。
- **可迁移点:** 左侧「流程导航 + 子项」的二级结构;冷色 UI / 暖色世界 的互补策略。

### B5 `stellaris_05_red_star_system.jpg`(1920×1080,meanLum 28.6 / meanSat 82.1)
- **构图:** 无任何 UI 的纯游戏画面:红巨星居中偏上,行星与飞船轨迹从下方穿过。
- **镜头:** 广角,主体占画幅 1/3;前景飞船引擎光形成第二视觉焦点。

- **材质:** 恒星表面颗粒噪声、行星暗面、引擎冷蓝光(与暖红形成互补)。
- **元素:** 恒星、行星、星尘、飞船+蓝色尾焰(唯一冷色)。
- **信息层级:** 视觉引导=恒星(亮)→飞船(动)→行星(结构)。
- **实测颜色:** 红黑系;accent #ff2702。
- **可迁移点:** 「暖色天体 + 冷色人造物」的对比配色;高饱和只给单一焦点。

### B11 `stellaris_11_megastructure_detail_panel.jpg`(596×407,原生 1:1,meanLum 58.9 / meanSat 20.6)
- **构图:** 详情面板:标题条(名称+类型 Megastructure)、右上齿轮+X、插画横幅、效果行列表、说明文字、两枚按钮(Complete / Dismantle)、底部页签(Megastructure | Chambers)、右下资源读数(Obers)。
- **镜头:** 无镜头,纯面板。
- **光照:** 面板深绿黑(实测 #0c0f0d 11.34%、#1f332d 10.32%、#151d19 8.55%),插画偏暗青;文字浅灰白。
- **材质:** 石/金属质感底板,标题条是浮雕浅色条;按钮有 1px 琥珀描边。

- **信息层级:** 标题→效果(收益,绿色)→ 说明(米白)→ 操作(按钮);Upkeep 用红色放在插画上方,提示成本。

## D. 字体与排版

### D1 字体族(一手可查)

| 层级 | 字体 | 证据 | 可信度 |
|---|---|---|---|
| 主菜单 | **Jura**(Light / Medium) | Paradox 官方 Wiki《Font_modding》(A6) | 已确证(官方 wiki) |
| 正文 | **Century Gothic** | 同上 | 已确证(官方 wiki) |
| 标题 | **Orbitron** | 同上 | 已确证(官方 wiki) |
| 弹窗 header | **Malgun Gothic** | 同上 | 已确证(官方 wiki) |
| 中文/日文 | 语言专用图集(官方汉化字体) | 同上 | 已确证(技术事实) |

> 说明:Jura / Orbitron / Century Gothic / Malgun Gothic 均为 Google Fonts 可得或系统内置;Stellaris 使用它们的方式是**离线转 bitmap**,所以观感与网页渲染不同(字重更硬、边缘无次像素)。

### D2 排版实现的技术事实(写进「产品可实现性」比字体本身更重要)

- 字体全部是 **BMFont 生成的 bitmap font**(`gfx/fonts/`),不是运行时 TTF 渲染。
- 单张字体图集上限 **16MB**;官方简体中文字体由 **11 张 14–16MB 图集**关联而成。
- DDS 图集必须 **DXT3/DXT5** 才支持半透明;字体定义在 `interface/*.gfx` 的 `bitmapfonts` 里(`color`、`textcolors`)。
- 结论:**Stellaris 的界面文字是「预烘焙像素」**,这也解释了它为什么能做到「小字号仍然锐利、但字号阶梯少」——它没有网页那样的动态排版能力。

### D3 观感结论(结合 B 节逐图)

- **字号阶梯少**:标题/面板头 ≈ 20–24px、正文 ≈ 11–13px、微标签 ≈ 9–10px(按 1920 宽截图**目测**,受 UI 缩放影响 ±1px)。信息量靠分组与图标,不靠字号层级堆叠。
- **字重**:标题中等偏硬(Medium/Semi),正文 Regular;不用 Light 做正文(位图化后 Light 会糊)。
- **字距**:大写标签(OUTLINER、SECTORS、CHAMBERS)有明显 **+0.05~0.1em 字距**;正文不加字距。
- **大小写**:标题用 Title Case,分组/字段标签用全大写;数值用等宽感数字(靠字体本身数字宽度接近)。
- **中英混排(推测,用于 ASTRA 中文界面)**:若使用同款 Jura/Orbitron,中文需另选 CJK 字体(如思源黑体 Medium),并**统一字面率**:中文 13px 等价英文 12px、中文行高 1.6、英文 1.45;全大写英文标签不要比中文重。

> 未确证项(标注推测):D3 的 px 值来自截图目测;字体在 UI 中的具体字重映射(哪个控件用 Medium/SemiBold)无法从公开资料确证。

## E. UI 信息架构解剖(机制层)

### E1 区域与网格
- **顶部资源条**:横贯全宽,高约 28–32px(目测),内容=「图标+数值+增减」一维排布,右侧是日期/速度控制。它的职责是**全局状态常驻**,永不遮挡地图中心。
- **左侧图标竖栏**:约 40px 宽,一列功能入口(科技/外交/舰队…),纯图标无文字。
- **右侧 Outliner**:约 298px 宽(实测裁切 1620–1918),可折叠分组(Sectors / Shipyards / Military Fleets / Civilian Ships…),行内=图标+名称+数值+状态点。**这是「对象列表」而非「页面」**。
- **中央世界**:银河图/星系图,唯一被允许大面积留黑与承载空间感的区域。
- **底部**:模式按钮(Close Galaxy Map)、系统铭牌、速度控制;动画/暂停状态用文字(如 Paused)常驻。
- **浮层**:管理窗、事件窗、tooltip 三层叠加,顺序为「世界 → 面板 → 解释」。面板不遮满屏,保留世界可见。

### E2 边框、切角、材质
- 面板边框=**1px 双线**(亮线+暗线夹出内凹感),实测列表行分隔为「1px 线 + 2–3px 间隙 + 1px 线」。
- **切角**:页签与面板角有小切角(45° 短边),不用大圆角;整体 0–2px 圆角。
- 材质靠「内阴影 + 顶部一道亮线」,不做模糊玻璃(和赛博朋克 2077 相反)。

### E3 图标语言
- 主图标=**金属徽章/盾形/六边形**,内部符号区分含义;有亮/暗/选中三态(亮度差,非灰度滤镜)。
- 功能图标=单色线性图标(白/浅青),尺寸小(目测 16–20px),常配数字角标。
- 资源图标=小尺寸彩色符号(物理青、社会绿、工程橙),颜色本身就是语义。

### E4 数据可视化形式
- **关系图**:星系节点 + hyperlane 折线(节点=符号,边=细线,方向不刻意强调)。
- **面积图**:势力领土=半透明多边形(低饱和填充,边界 1px 亮线)。
- **阶梯进度**:意识形态的六边形节点 I/II/III(灰=未达/绿=已填)。
- **成本 chips**:图标+数值成对,成对出现在列表行与 tooltip 里。
- **行列表**:63px 行高、双分隔线、图标+名称+数值+状态。
- **技术图解**:线框主体+引线+标注(B7)。

### E5 状态语言(实测)
- 绿(薄荷/青绿)= 正向效果、可执行、已达成。
- 红 = 阻断、维护成本、危险、未达成条件。
- 琥珀/金 = 资源、花费、稀有、版本/身份。
- 白/近白 = 中性正文;灰 = 次要信息、未选中。
- 另有**暂停态**:画面中下部出现暖金色 Paused 字样(实测 B3/B13),不靠弹窗。
- 不可用态:文字变红 + 条件说明(「Cannot be amended before …」),而不是把控件置灰。

## F. 动效与转场语言

> **口径提醒**:本报告基于静态截图与公开资料,以下「已确认」为可从截图/官方信息推断的事实;其余为**推测**,需 lead 决定是否采用。

- **已确认的静态线索**:暂停态文字(Paused)常驻;速度控制(1–5 档)是核心交互,说明游戏节奏由玩家控制,UI 动效预算低。bitmap font 与贴图面板的管线说明 UI 动画以「贴图切换/淡入淡出」为主。
- **推测的动效语言(与 ASTRA 相关)**:
  1. **低位移、低频率**:面板不滑动,用淡入 + 轻微亮度变化(0.15–0.25s);避免持续运动干扰读图。
  2. **地图层动画**:hyperlane 选中时线体加亮/流动;舰队移动用「点+线段」推进而非弹性动画。
  3. **状态切换用颜色而非形变**:绿→红、亮→暗,不缩放不弹跳。
  4. **tooltip**:淡入(≈0.12s)+ 不跟随鼠标抖动,位置避让。
  5. **事件窗**:从边缘淡入、背景压暗(不模糊),关闭时反向。
- **可迁移的机制**:「动效预算极低 + 状态颜色承担反馈」非常契合 ASTRA 这种**长时间常驻的监控型界面**;而全屏转场、弹性回弹、粒子扫光都属于禁止照搬的「游戏皮」。

## G. 可迁移机制 vs 禁止照搬的皮

| 线网 | 节点+边(hyperlane)的图语法;低饱和线、少量高亮 | 具体的 hyperlane 走线、星名、星系图标 |
| 领土 | 半透明色块表达「域/归属」 | 势力徽章、旗帜、颜色绑定的具体阵营 |
| 列表 | 63px 行高、双 1px 分隔、图标+名称+数值+状态点 | 行内具体图标库、资源符号 |
| 状态色 | 绿正向/红阻断/琥珀成本 的三色互斥语义 | Stellaris 具体色值组合与渐变 |
| 图标 | 「同外形框架 + 不同内部符号」+ 亮/暗两态 | 金属錾刻徽章的具体纹章、舰船剪影 |
| 字体 | 小字号阶梯 + 大写标签字距 | Jura/Century Gothic/Orbitron 的原样使用与描边花纹 |
| 事件窗 | 插画头 + 正文 + 图标选项行 + 背景压暗 | 事件插画本身(角色、巨型结构、场景) |
| 动效 | 低预算、颜色反馈、淡入淡出 | 全屏转场、镜头推拉、游戏化粒子 |

**一句话:** 借它的「**暗底 + 线网 + 三色语义 + 列表行语法**」,不借它的「**星云/徽章/插画/字体皮肤**」。

## H. 3 条可直接落地的设计规则(来自实测)

### H1 「近黑 + 三级面板」的层级规则
- 画布底:`#070a09`(实测面板底区间 `#070908`–`#0d0f10`);世界层可用 `#04070e`(蓝黑)/`#091016` 与 UI 层区分。
- 面板三级:`L0 #070908`(画布)→ `L1 #0c1010`(面板)→ `L2 #172621`(浮起/tooltip 可用 `#130d0d` 暖棕黑)。层级差用 **+4~10% 亮度**,不用阴影/描边堆叠。
- 分隔线:**1px + 2px 间隙的 double line**(实测),线色 `#1c2422`(亮)/`#0a0f0d`(暗);行高 **63px**、行内字号 12–13px(按截图 1× 换算)。
- 面板圆角 **0–2px**,角部小切角(45°,4–6px);禁止大圆角与玻璃模糊。

### H2 「三色状态 + 面积配额」规则
- 正向/可执行:`#00d2a2`;成本/资源:`#f1bd3b`;阻断/危险:`#da1519`。三色**语义互斥**,同一元素不同时用两色。
- 配额:强调色总量 ≤ 面板面积 **2%**;红色仅用于阻断/危险,**单屏红色文字不超过 2 行/0.5% 面积**(实测红文字呈现为细长行,不铺面)。
- 对比度:正文近白 `#e8f2ef` 对 `#070908` ≈ 17:1(实测白 `#f2f2f2` 对 `#070908` = **17.84:1**);红色文字如需保证可读,用**提亮红** `#ff6b5e` 量级(对 `#0a0a0a` ≈ **6.2:1** 的红色参考值来自另一参考系实测),不要用暗红 `#a51806`(对比仅 2.58:1)。

### H3 「图标优先 + 微标签」规则
- 行内结构:图标 **20–24px**(目测)→ 名称 13px → 数值 12px 等宽感 → 状态点 6px(圆点,绿/红/灰)。
- 分组标题:全大写 **10px**、字距 **+0.08em**、颜色 `#6b7a75`(低对比 30–40%);正文 12–13px、行高 1.6。
- 数值对齐:右对齐、千分位;单位后缀用 10px 灰(`+0.5`、`/180`),不重复图标含义。

## I. 与 ASTRA 观测台的关联(四类界面映射)

### I1 星图 / 星座(会话与 agent 的关系图)
- 借:银河图的「节点=符号 + 边=细线 + 大面积黑」;节点用**我们自己的 agent 徽记**(不用星系图标);关系线用 hyperlane 的折线语法。
- 借:outliner 的右侧分组列表(session / agent / tool / alert),可折叠、行内=图标+名称+数值+状态点。
- 借:领土色块→「域/范围」:一个 session 的上下文范围、一个 team 的写入域,用低饱和半透明填充 + 1px 边界。
- 不要:星云照片、星名、具体势力配色、Stellaris 徽章。

### I2 仪表盘(全局状态)
- 借:顶部资源条——图标+数值+增减(delta)的一维排布,常驻不遮主体;右侧放时间/节流控制。
- 借:三色语义:绿=健康、琥珀=接近阈值/成本、红=越界;数值 12px 等宽、delta 10px 灰。
- 借:暂停态文字替代弹窗——「流式暂停/冻结」用一行暖金色状态字,不用 modal。

### I3 事件账本(账本/时间线)
- 借:事件窗五段式(B11):标题 / 效果表 / 说明 / 操作 / 页签。
- 借:列表行语法:63px 行高、双 1px 分隔、图标+名称+数值+时间戳;可折叠分组。
- 借:tooltip 三段式:标题(琥珀)/ 成本(图标+数值)/ 效果(绿,缩进列表)。
- 借:选项行的「图标+横条+居中文字」布局,用于「批准/拒绝/稍后」这类等权动作。

### I4 告警(过载/异常)
- 借:红色只给阻断/危险;不可用态用「红字+条件说明」而非置灰(与 Stellaris 一致)。
- 借:状态色块 + 进度阶梯(六边形节点改为圆角矩形/圆点)表达「还有几级才触发」。
- 借:事件插画位置→我们用**抽象数据纹理/热力条**替代具象插画,避免抄美术。
- 不借:「Paused」文字直接挪用;改为我们自己的状态词(冻结/降级/静默)。

### I5 对最终产品的硬约束(交给 lead)
1. 所有图像资产必须自绘;`docs/research/assets/stellaris/` 仅供比对与测量,**不进入 apps/**。
2. 若采用 Jura/Orbitron/Century Gothic,须换用 OFL 字体并自查授权(Orbitron/Jura 为 OFL;Century Gothic 为商业字体,**不可用**)。
3. 红/绿/琥珀三色语义一旦定下,不得在其他语义复用(否则告警失灵)。
4. 调色板以本报告 C 节实测为锚,允许 ±10% 明度微调,但**面积配额(强调色 ≤2%)与近黑主色占比(≥60%)**必须保持。
