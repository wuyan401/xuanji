# 璇玑 · 验收手册（v2.5）

> 给「亲自验收」用的一页纸。全部步骤都在本机 `http://127.0.0.1:8787/` 上完成，不需要联网。
> 建议先按 1–4 节目视走一遍（约 10 分钟），再跑 5 节的自动化命令对账。

## 0. 环境确认

```bash
# 服务在跑吗（默认 8787；若没起：pnpm build && pnpm start）
node -e "fetch('http://127.0.0.1:8787/api/health').then(r=>r.json()).then(h=>console.log(h.ok,h.source,h.sessions))"
```

浏览器打开 <http://127.0.0.1:8787/>，**Ctrl+F5 强刷**（v2.5 换了前端产物）。
预期顶栏：`璇玑 · 授时` / 时辰 + 走秒 / `行 n 驻 m 藏 N` / 文速 / 览·书·作·讯·遣 / 主题铭牌「璇玑｜深空」/ 连接徽标「实况」。

可选参数（URL 直接拼）：

| 参数 | 作用 |
|---|---|
| `?view=system` | 直接进「整机仪象」 |
| `?theme=scifi` | 直接进「深空」主题 |
| `?boot=0` | 跳过授时开机 |
| `?motion=off` | 强制 reduced-motion（设计闸门） |
| `?reset=1` | 忽略视野记忆 |
| `?demo=1` | 演练数据（8 个假 agent，用于空数据时检查动效） |

## 1. 三项签名装置（先看设计是否成立）

1. **授时开机**：硬刷新后 0–3.2s：黑场微光 → 三行自检（校历/候漏/观星，含「本机智能体 N 位 · 诸源 M 源」）→ 钟鸣「授 时」44px → 虹膜三环展开。按任意键可跳过。
2. **浑仪**：37 个分野弧（内圈 3 条星轨 + 外围分野弧带 + 授时环 + 器数环）。星 = agent，星色 = 来源状态，环上小点 = 器数。**在行的星与中枢之间有一条持续工作光流**。
3. **《起居注》**：左下账本实时落墨——每行「时辰 · 行/驻/藏 · 分野 · 器用 [类] 工具名 · 耗时」，错误行左侧朱线 +〔朱批〕，审批行〔钤印〕；行首小签 = 来源。

## 2. v2.4 四项反馈逐条验收（当前版本重点）

| # | 操作 | 期望现象 |
|---|---|---|
| ① 工作光流 · 连接 | 等一位 agent 开工（或开 `?demo=1` 观察 live 星） | 从该星边缘向中枢画入一条 ~320ms 的亮头（星侧闪点 + 涟漪），随后变成一条常驻细线 |
| ② 持续光流 + 工具光束改锚 | 盯住任意 live 星与中枢之间，等《起居注》出新行 | 细线上有光粒**持续**朝中枢跑（密度随文速/工具速率，最低 2 粒/秒）；出工具时，从这条线上（不是星缘）射出一道五类光束打向中枢 |
| ③ 断开 | 等该会话变 idle/ended（或切到历史星看它没有流） | 粒子停发、细线从星侧退淡、末段收束成一个闪点后消失；历史 ended 星没有常驻流 |
| ④ 深空配色 + 随势转速 | 按 **`T`** 切「深空」（或 `?theme=scifi`），等 live 活跃时对比静默时 | 光流/连接/工具光束全部转冷色（青蓝/荧光青绿，画面几乎无暖色）；外圈旋转在活跃时明显加快（约 1.1× 起）并在静默后回落；切回璇玑恢复原速原色 |

> 想同时看「连接 / 流动 / 断开」三段：`?demo=1` 下 8 个假 agent 的状态会来回翻，比真实数据好等。

## 2.5 v2.5 第三视图《百工 · 器群》（当前版本重点）

| 检查 | 操作 | 预期 |
|---|---|---|
| 视图循环 | 连按 `0`：智能体 → 整机 → 百工 → 智能体 | 顶栏铭牌出现三枚「智能体 / 整机 / 百工」，第三枚选中时 canvas 换成机械盘面 |
| 全进程可数 | 停在百工视图 | 顶栏「进程 200 / CPU x% / 内存 y% / 线程 5,xxx」；《工籍》名册严格按 CPU 降序；盘面上芯片数=进程数（最多 220） |
| 三档轨道 | 看盘面 | 内圈 CPU 轨 / 中圈内存轨 / 外圈沉积轨；高 CPU 芯片是冷白实心条，沉积轨是一片暗骨白点环 |
| 数据总线 | 看芯片到中心 | 每条芯片有一条径向虚线（`lineDashOffset` marching）汇向机轴；沉积轨缓慢流动、不静止 |
| 机械节拍 | 盯 4 秒 | 机轴每秒瞬转 6°、总线环孔位逐一点亮、屏幕自上而下 2 条扫描线；没有任何缓动/回弹 |
| 选中进程 | 点《工籍》任一行或盘面芯片 | 芯片出现 2px 外描边 + 选中环 + 四角刻；《器牒》切到档案（PID/名称/CPU/内存/线程/所属轨 +「← 进程总览」）；`Esc` 清选 |
| 深空主题 | 按 `T` | 器群换成青蓝/荧光青绿；工籍/器牒刻度列出现；再按 `T` 回到璇玑 |
| 与智能体视图的区别 | 来回按 `0` | 智能体：曲线/节拍/暖金/呼吸/留痕；百工：直线/等速/钢灰冷白/严格 1Hz/无痕——气质刻意对立 |

## 3. v2.3 八项（回归检查，仍应成立）

| # | 操作 | 期望现象 |
|---|---|---|
| ① 不闪/不错位 | 静看浑仪 30 秒，再看星带缓慢游动 | 星没有随机闪一下；没有星突然跳到别处；只有匀速漂移 + 呼吸 |
| ② 缩放亮度稳 | 鼠标对准核心，**连续滚轮放大 5–8 格** | 画面平滑推近、亮度不发暗/不跳变；光标下的那圈刻线不动 |
| ③ 越强越靠内 | 看内圈（near 0.42R）vs 外圈（0.64R） | 大且亮的星（文量大/活跃）集中在内圈，小而暗的散在外圈 |
| ④ 机器运转 | 盯住分野弧带与最外器数环 | 弧上有细小流点沿弧滑动；有工具事件时对应弧段脉冲、器数环亮一格 |
| ⑤ 外环反馈 | 让某个 agent 跑一次工具 | 该 agent 所在分野弧段亮一下，器数环对应块亮起后 400ms 衰减 |
| ⑥ 协作通讯 | 等一条 `send_message` / 团队任务 / 子 agent 出生 | 星之间出现 1px 弧线，2–4 个光包沿弧飞过去（消失 ~0.9s） |
| ⑦ 出生动画 | 用 `?demo=1` 或等新会话出现 | 新星从分野弧径向飞入、星核点亮、涟漪扩散；新分野弧段展开 |
| ⑧ 核心 + 主题 | 滚轮滚到 3× / 6× 看中心；按 `T` 切主题 | 中心六层：三层同心核 + 椭圆轨道粒子 + 极坐标格栅 + 符文短弧 + 脉冲波 + 焦点束；`T` 切「深空」后整盘变青蓝舰桥风，HUD 同步换皮，刷新后保持 |
| ⑨ 放大字号（v2.4.3） | 打开即看首屏分野名/二十八宿（默认字号 1.4 → 屏显 1.60×）；再滚轮放大到 2.4×、6.7× 看字跟着变大；仍嫌小按 `/` 打开调参台 → 质感 → **字号** 拉到 1.8–2.4 | 字**跟着变大**：首屏 1.60×、2.4× 约 2.35×、6.7× 约 3.92×；「字号」滑杆可整体再放大（默认 1.4、最大 2.4；URL `?p=textBoost:2.4` 可复现）；绝不会出现「越放大字越小」 |

## 6. 已知取舍（验收时不要当成 bug）

- 386 颗 ended 星是最暗的一层淡骨白实心星——真实状态，想只看在行的按 `7` 守夜或点分野总览里的 live 行。
- **工作光流只画给 live 星**：历史 ended 星没有常驻流（否则 380+ 条线会糊成一片），断开后只留一个短闪点。
- 星牒会「自动跟随」：收到 error 事件且当前没有选中会话时，星牒会切到那个会话档案；点档案顶部「← 分野总览」即可返回。
- 37 个分野时 1440 宽下分野双行标签可能轻微重叠（已随缩放增距，未做完整避让）。
- 主题切换时 canvas 400ms 与 HUD 320ms 有约 80ms 刻意错位（避免整屏同时变色太硬）；深空下工具光束色相 161°（落在设计区间 160–220°）。
- Codex 本机只有配置没有 rollout：界面如实显示「未发现」，不生成假会话。
- 整机遥测仅 Windows（PowerShell 采样）；非 Windows 显示「遥测不可用」而不是发 0。
- 《百工》最多画 220 个进程（后端 `PROC_LIMIT` 可调），超出按 CPU 降序截断；该视图没有自动运镜（与另两视图刻意区分），只有滚轮 0.8–4.0× 与拖拽 ±0.8R。
